# ADR 0024：场景设置和暂停菜单

## 状态

2026-11-28 采用并实现。更新 [ADR 0006](0006-demo-scenes-and-controls.md) 记录的场景切换与退出操作。

## 背景

演示的启动场景来自 [demo_settings]。编辑磁盘上的场景路径后，用户需要在当前窗口重置演示并应用新设置。

## 决策与实现

- scene 保存相对 assets/ 的 .destruction.json 路径，默认是矩形楼。场景快捷键随该变更移除。
- Esc 打开或关闭暂停菜单。打开时暂停虚拟时钟、释放鼠标并暂停场景输入。菜单提供 Resume、Reload 和 Quit。
- Reload 使用独立的 Bevy 类型注册表重读 SettingsPlugin。候选建筑完成资源准备后替换当前建筑，同时清理撞击物和粒子、重置相机并应用新的开关。设置文件无法解析或候选加载失败时，菜单显示错误并保留当前建筑。

## 备选方案与取舍

重新启动进程也能读取用户设置，但会重新创建窗口和渲染设备。当前窗口保留渲染上下文，用候选建筑的准备状态决定切换时机。

## 验证结果

初次实现时，Rust 路径校验回归通过。当前 Python 原生输入验收检查 F1/F2 保持原场景，并覆盖暂停与恢复、同场景重置、跨场景重载，以及通过菜单退出。TOML 无法解析或场景资源缺失时，验收检查菜单显示错误并保留当前场景。

## 未决问题

当前菜单覆盖演示场景的加载与重置。
