# ADR 0022：由独立脚本驱动无窗验收场景

## 状态

2026-11-23 采用并实现。更新 [ADR 0018](0018-windowless-acceptance.md) 的无窗验收场景选择方式。

2026-11-28 随[桌面设置迁移](0006-demo-scenes-and-controls.md)更新验收输入和报告的开关字段。

## 背景

验收二进制先前直接解析场景、资产、探针、输出路径和性能参数。不同用例需要不同的输入、断言和报告，同时可共用一个无窗 Bevy 应用入口。

## 决策与实现

- `controls.py`、`gameplay.py`、八个固定帧探针脚本和 `profile.py` 提供独立入口。参数和用例矩阵由 Python 驱动维护。`run.py` 同时提供单项、基线和完整验收。
- 二进制无参数启动。交互脚本使用默认演示场景。固定帧脚本在子进程环境中传递场景配置，Rust 在装配前校验配置，设置资产、输出、探针和渲染策略。固定步断言、阶段截图、回放和性能测量继续在现有探针中执行。
- 场景 JSON 使用正向布尔字段 `stress`、`vfx`、`detail` 和 `soft_particles`，缺省时启用。Python 的禁用参数将对应字段设为 `false`。冒烟报告将开关记在 `settings` 对象中，顶层保留特效与破口边带的指标。

## 备选方案与取舍

每个探针使用单独的 Rust 二进制会重复构建和维护无窗装配。通过 BRP 在运行中选择探针需要额外协调初始资产、固定时钟和渲染管线配置。脚本传递启动配置，允许共用二进制并在初始化前确定探针设置。

## 验证要求与结果

检查独立脚本和汇总矩阵，确认报告中的进程命令只有可执行文件。运行原生交互、固定帧基线和性能验收，确认报告、截图和退出码继续按原断言生成。

两组原生交互、17 个固定帧用例和性能脚本均通过。20 次运行的报告都记录了无参数启动。无效场景配置在应用初始化前被拒绝，进程返回非零退出码。

## 未决问题

引入需要首帧前初始化的新探针时，应核对它期望的时钟、渲染与资产状态。
