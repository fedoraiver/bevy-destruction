# ADR 0020：正式不规则预破碎与多面片承载接口

## 状态

- 日期：2026-11-17。
- 已采用并实现；六个正式 v2 场景已烘焙，严格元数据、实际 GLB 接触覆盖与初始自重验收通过。制作端最终套件及图形破坏验收结果继续按实际结果记录。
- 用户明确要求替换正式场景分块，推进 [ADR 0018](0018-natural-irregular-prefracture.md) 的隔离原型。

## 背景

替换前六个场景使用平面凸 Voronoi 块；自然起伏的共同边界要求非凸逻辑块和复合凸碰撞体。仅替换显示网格会使点击、碰撞、质量与承载面不一致。原单平面 Bond 不能通过平均法线精确表达非平面界面。

运行时保持每个逻辑块六个刚体自由度，不显示弹性形变。原型的随机边界、目标尺度和保质量修复作为制作端起点；不能以密集采样微片代替逻辑碎块，否则结构规模和碰撞成本会失控。

## 决策

- 新资产采用格式 v2。最初继续读取 v1 的决定已由用户后续要求及 [ADR 0022](0022-rust-module-layout.md) 取代；当前只接受 v2。每个父 Bond 必须包含 `patches`，每片记录真实平面凸多边形 `vertices`、面积、中心、从 a 指向 b 的法线及面积二阶矩，均在资产坐标系。父 Bond 保持一个 Chunk 对一条连接的身份和断裂状态。
- 父级面积、面积加权中心、法线与完整面积二阶矩用于汇总和显示。非平面承载组装使用各片的方向、几何和力臂，不将父级平均法线当作完整截面。
- 每片仍使用现有法向/切向弹性界面近似。所有子片使用同一个父级等效长度 `|center-Ca|+|center-Cb|`，避免纯粹细分平面改变厚度/刚度标定。按片的 `JᵀKJ` 相加，节点自由度及连接图规模不随面片数增加。
- 恢复各片应力，并将合力及包含力臂的合矩归并到父连接中心。父承载率取各片最高值，父连接失效时整体断开；没有引入面片逐个剥离、连续裂纹传播或显示顶点形变。
- 暴露面直接读取规范多边形，并核对显示几何；按 ADR 0022 移除旧共面重建回退。碰撞使用分区的凸子体复合形状，质量和完整惯性从实际逻辑实体计算一次，不按子代理重复累加。
- 制作端保留建筑外轮廓、开口、材料及锚定语义；随机配置必须可复现，失败明确报告，不丢弃正体积碎片。采样精度和目标碎块尺度分开设定。

## 正式制作参数与目录

- 适用于现有水平/竖直凸棱柱构件：同一面墙、楼层或框按语义及材料组成共享源域；先合并相容的源厚度轮廓，避免原面板对角线形成强制分块线。门窗和庭院从固定源域中扣除，不随噪声扭曲。
- `fracture_size` 是目标尺度；采样间距为目标尺度的 `0.28`。站点由每站点 512 个候选中选取的良好间隔随机样本产生，最小间距为目标尺度的 `0.6`。非周期、独立旋转的三层梯度噪声使用波长/幅值比例 `(2.5,0.32)、(1.0,0.12)、(0.45,0.04)`，不采用正弦波或规则站点格。
- 连通逻辑区域投影面积限定为源域面积除以初始站点数的 `[0.2,3.0]` 倍，投影 AABB 对角线不超过 `3*fracture_size`；长宽比上限取 `max(6,2*fracture_size/源域继承宽度)`。微小连通片只能沿真实有限公共面转交相容邻区，重新核对尺寸、体积和完整惯性；不能跨开口连接或删除正体积。
- 每源域最多 256 个站点、12000 个微单元，每逻辑块最多 48 个凸代理，整资产最多 2048 个逻辑块。每源域最多尝试 12 个由输入种子、域 ID 和尝试号共同确定的配置，失败原因逐项记录；无静默回退或无界重试。六场景实测每块最多 28 个凸代理。
- 接触共面性在实际凸重叠域内按 `20 µm` 检查，不能因微小面法线的量化角度噪声而拿相邻大面远处的顶点否定局部接触。所有序列化承载面片的最小平面宽度必须严格大于 `20 µm`，面积和二维截面矩均须可解析；排除的边接触明确审计，材料体积保持。
- 按 [ADR 0023](0023-source-mesh-and-contact-surface-overlays.md) 保留原源碎块网格，离线仅作整面材质分类。导出后对实际 GLB 支撑域的接触微修正限制在 `min(4 ULP,40 µm)`，并核对位移、面积壳层预算及双端覆盖；重算面片与父连接全部几何元数据。没有放宽几何或张量验证门槛。

## 备选方案与取舍

- 单凸包包住曲面块：容易实现，但填平凹部和开口、造成邻块代理穿透，未采用。
- 只对显示断面加噪声：无法满足实际分区一致性目标，未采用。
- 每个面片成为独立 Bond：增加图边及断裂状态，且需要新的局部剥离规则；本轮采用一个父连接包含多片。
- 宏观平均平面等效：成本较低，但丢失局部方向及力臂。本轮选择分片积分，仍承认这是已标定弹性界面网络的扩展，而非连续体有限元或完整应力波。
- 精确代理比旧平面代理更多。优先减少冗余采样/合并相容凸区域，并记录六个真实场景的逻辑块、代理、面片和运行时开销；不能以关闭碰撞或削减断裂规模验收。

## 验证要求

- 拒绝旧格式及不合格 v2 数据、局部坐标导出后的共享界面及开口净空。
- 平面细分前后刚度、解、反力与峰值应力一致；折面与独立面积积分的能量一致，恢复合力/合矩满足节点平衡。
- 六个实际场景全部加载和初始自重求解有效；点击、碰撞、部分坍塌与落地保留有限质量和成组结构。
- 随机边界和尺寸通过可复现实物截图检查；不存在规则波浪、数值裂缝、填窗或初始化时代理互相炸开。
- 实测代理/面片成本、加载和求解时间，记录验收场景及其局限。

## 已完成验证

- `natural_union.py` 已实现真实有限面积邻接、部分共面内面消除、T 型接点补边，以及基于邻接堆的凸合并。凸包只选择原始规范坐标，避免在全局 50 m 处经过 float32 往返后破坏公共边界；凸合并同时检验外皮的支撑平面及原始体积，不能仅凭相对体积预算填掉细窄凹口。
- 13 项 Blender 合并回归通过：整面/部分面、边点不连接、带洞环的完整惯性及净空、确定性/顺序变化、48 微格合成一个代理、50 m 处旋转平移后的共享面，以及低于相对体积预算的小凹口保留。
- 正式小楼试装暴露了源面板对角线量化产生的不可解析薄面：补 T 接点后，该面成为成对反向边的回退轮廓。仅消除已焊接退化轮廓中的反向边，真实多轮廓仍报错；冻结失败实例修复后封闭，体积 `0.847913490125 → 0.847913498628 m³`，质心和完整惯性回归通过。此数值修复不删除独立正体积碎块。
- 正式墙角的约 0.015 m 代理在世界坐标约 4 m 处被 float32 舍入后，旧三角拓扑不再是其顶点集的凸包。凸包计算先归心并归一化，若 BMesh 拓扑仍不满足原始双精度点的支撑平面，则使用双精度增量凸包；返回值始终引用原输入坐标。冻结实例重建后通过原凸性校验，体积变化 `4.03e-12 m³`。制作端需对实际写入后的代理再次重建并审计，不通过统一放松凸性容差解决。
- 内墙试装发现一条边被四片使用：初次裁剪后的外皮中仍有一对有限面积内面。仅在焊接后边使用数大于二时，对原外皮执行一次有界的内面抵消；真正只沿边接触的非流形体仍拒绝。冻结实例修复后封闭，体积 `0.431148084818 m³`，质心和完整惯性保持在回归精度内。
- 几何内面抵消和分区邻接的有限宽度判据分开：正面积、可解析的内部面不能因为低于邻接阈值而残留在实体内部。1 µm 窄连接的冻结回归保持完整体积和质心；边/点接触仍不产生邻接。
- BMesh 在规范输入点上产生共线三角形时，选择已有双精度凸包重建，而非提前抛错阻断整个确定性配置。26 面实际失败输入的回归证明凸性、原始顶点集合和总体积保持；没有放松源几何校验。
- 多面片组装与恢复已实现；平面细分不变性及折面独立面积积分/父连接平衡测试通过。局部撞击也按各片方向计算，沿用原面积加权和 10 ms 标定；折面剪切与平面细分不变性回归通过。
- v2 读取与暴露面覆盖检查已实现，拒绝错误绕序、法线、面积/中心/二阶矩、重复覆盖和缺失显示接触面。接入早期的 97 项 Rust 回归仅验证了当时实现，不代表正式替换完成。该阶段曾保留的 v1 窄支撑历史夹具已按 ADR 0022 移除；当前没有 v1 读取或回退路径。
- v2 显示面片的共面合并额外要求面积守恒，避免旧合并容差填掉较小凹口；不能满足时保留原真实面片。小凹口回归及当时包含显示/坍塌工具的 100 项 Rust 回归通过；该阶段尚未完成正式 v2 资产图形验收，最终结果见 ADR 0023。
- 坍塌验收已改为依据实际楼板高度与连接图选择偏侧支撑路径，不依赖旧 Voronoi ID 或固定碎块计数；大块条件按原上部质量比例衡量。几何策略在旧正式矩形楼上独立实测：保留 2 块支撑、移除 61 块，上部 `91,282.78 kg` 成组释放，下降 `1.509 m`、倾斜 `1.003 rad`，有静态残桩接触、3 条强度断键、0 次求解失败。此为新版验收工具的旧资产对照，不替代新分块验收；最终资产的结果见 ADR 0023。
- 六个新目录均已完成实际清单、GLB 哈希/材质角色、双端接触覆盖及自重平衡验收；局部接触修复前后的 `chunks`、`anchors`、`authoring_audit` 逐字段完全相等，包含全部凸代理、体积、质量、质心和完整惯性。GLB 材质分类另有逐顶点、逐面精确不变断言。最终显示接触及图形结果见 ADR 0023。
- 庭院原有外壳面积回归最初偏差 `+0.004093 m²`。局部接触诊断使未筛选接触总面积从 `222.1885542850` 恢复至 `222.1906198558 m²`，恰好解释遗漏接触；统一修复六场景后，最终净外壳与原构件外壳推算仅差约 `-3.6e-5 m²`，原 `1e-6` 相对面积门槛不变并通过，未通过放宽误差或删除断言验收。
- 最终 Blender 5.2.3 后台去重套件 63 项通过：几何 5、原破碎几何 5、表面 6、凸合并 13、自然制作/v2 14、完整制作工具/UI/事务 10、六场景目录 4、正式 GLB 表面 6。包含同一集合重复导出的 ID 与 JSON 字节稳定、发布失败保留旧集合/资产、实际 L 形量化接触的微修正，以及超出微修正预算必须拒绝的负例。测试未改变物理阈值或几何门槛。
- 最终 `bevy_destruction-0.3.0.zip` 的 12 个 Python 文件与冻结源码逐字节相同；在独立 `BLENDER_USER_SCRIPTS` 目录安装、启用、面板注册、停用通过。没有更改常用插件目录或保存 Blender 用户配置。

## 未决问题与来源

薄壁/跨源构件区域的自然边界、复杂几何的局部最小宽度、碰撞代理预算和多面片最高应力准则的进一步标定需要持续检查。来源为本仓库原型与正式制作、加载、接触和应力实现，以及 ADR 0018 中已经列明的原始资料。
