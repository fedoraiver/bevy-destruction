# ADR 0008：破坏 VFX 的冲击感与暴露破口边缘细节

- 状态：部分已采用（下方实施决策已实现；离线共享切割面、six-way、音效仍为提议）
- 日期：2026-11-17
- 关联：[ADR 0007](0007-bevy-bsn-fracture-interaction-demo.md)、[ADR 0006](0006-blender-authoring-tool-and-asset-format.md)

## 背景与目标

用户要求调研怎样让 VFX 更能 sell 破坏，以及怎样增加被破坏网格的边缘细节。这里将 sell 理解为：玩家能读出冲击、碎裂、重量和材料，而不是仅知道发生了一次点击。

本记录保留原调研与备选路线，并在下方单独记录采用的实现、参数与验证。调研中的“现状”指提交 `f4bae1c` 时的版本；已采用的运行时改进不改变资产格式、破坏范围或结构物理规则。

## 调研时已核实的现状（历史）

| 现状 | 对观感的影响（设计判断） | 仓库证据 |
| --- | --- | --- |

清单统计也显示尺度不匹配：三个资产的碎块最大轴尺寸中位数分别约为 rectangle 1.696m、l_shape 1.577m、courtyard 2.097m；质量中位数约为 524 / 476 / 955kg。这是按现有代理和清单计算的资产数据，不是实物测量。删除米级几何却只出现几厘米方块，很难表达大块材料去了哪里；VFX 不能被误称为守恒的真实碎裂模拟。

## 资料支持的方向

- Frostbite 的破坏表现将移除主体、补充破口周边 detail mesh、叠加破坏材质以及粒子/碎屑组合起来，说明几何、材质、动态效果应共同服务于破口，而不是全部寄托于烟尘。[S1]
- SideFX 的 Debris Source 从已分离的内部表面发射，并保留体积、深度、年龄等属性。这支持“从真实新暴露区域取样”，而非只从命中中心发射。[S2]
- Soft particles 通过粒子和场景深度差衰减相交区域；透明大面片的重叠和屏幕填充也是重要成本，粒子数量不是完整预算。[S3]
- Six-way lighting 用六个方向的烘焙光照响应增强烟尘的受光层次；它仍是面片近似，不能解决自由相机贴近/穿入面片时的全部问题。[S4]
- SideFX 明确区分混凝土角点 chipping、布尔 edge detail 和 interior detail，并支持单独代理；这种层级划分可借鉴到 Blender 流程，无须引入 Houdini 作为依赖。[S5–S7]

## VFX 提议：先建立因果与节奏

以下时间、数量和尺度均为本项目的首轮试调区间，不是资料给出的标准、物理测量或已经验证的默认值。仍立即提交逻辑删块，不通过延迟伤害或额外连删建筑来配合特效。

| 时间/阶段 | 表现目标 | 建议起点 |
| --- | --- | --- |
| 0–80ms：接触粉爆 | 点击当帧读到短促冲击 | 紧贴命中面的扇形细粉，快速展开；普通混凝土不默认加火球、强闪光或火花 |
| 40–350ms：主碎屑 | 看清材料离开破口，形成重量线索 | 4–8 种共享的不规则石片网格，混合少量约 5–25cm 主碎屑与细屑；形状/厚度应受源材料和薄墙尺寸约束 |
| 80–1500ms：尘团 | 用卷曲扩散承接破碎，而非遮住全部结果 | 2–4 套非圆形短序列烟尘，先快后慢扩张，随机朝向/播放速度，连续透明度曲线；约 0.3–0.6s 后逐步露出破口 |
| 0.3–3s：边缘余韵 | 让刚形成的边缘继续掉灰 | 从新暴露边和表面发射少量短时落屑；粗屑受重力，尘团以阻力、轻微上浮和低频涡动为主 |

需要同时解决以下问题：

1. **事件携带破坏上下文。** 建议增加材料类别、被删体积、暴露面积及发射面采样位置/法线。第一步可先利用现有 Chunk 和 Bond 数据得到规模及有方向的近似；后续使用真实 patch 三角面按面积采样、边界按长度采样。鼠标点击只有视觉强度，不应伪装成已经求解的能量/冲量。
2. **分离各层的分布。** 粗屑沿主冲击方向和各自暴露面法线发出，叠加受限切向扰动；烟尘沿破口展开。法线应从存活侧朝已删除侧：现有 `Bond.normal` 固定由 a 指向 b，a 存活时用原方向，b 存活时取反；真实 patch 进一步使用局部三角面法线。不能把每个接触面都按同一命中法线处理。可用 Curl noise 提供可控涡动，但简单加噪声并不自动提供避墙/碰撞能力。[S8]
3. **碎屑有几何变化和短暂落地行为。** 首版只让少量可读的主碎屑使用限额的碰撞/反弹，其他仍为装饰粒子。现有场景没有无限地面平面，不能用一个假想 Y=0 平面代替楼板、洞口和真实建筑查询。不要把所有 640 粒子变成 Avian 刚体，也不要给全部主碎屑统一缩小消失。
4. **形状、透明度和运动分别控制。** 用烟尘 flipbook/噪声轮廓替换纯径向圆斑；轻微材质颜色变化不等于随机彩色粉尘。先试廉价环境光与主光响应，主视觉尘团再考虑 six-way。
5. **预算保留每次新命中的反馈。** 对接触粉爆、主碎屑、烟尘分别设预算；额度不足时优先削减旧的低优先烟尘，为新命中保留短反馈。加入距离/屏幕面积 LOD，同时记录透明覆盖和 GPU 时间，不能只提高 640 的上限。

可最后补同步的断裂声、主碎屑落地声和可关闭的轻微视图震动。它们是表现补强，不替代几何细节；自由飞行下不建议默认强震屏、hit-stop 或自动拉动视角。

### Bevy 0.20 落点与兼容性

- 保留现有 ECS/共享网格和材质即可先验证时序、形状、方向及层级预算，不必先迁移整个粒子系统。
- Soft particles 可从相机 `DepthPrepass` 起步，在 WESL 中比较同一坐标系下的粒子/不透明场景距离，加入相交淡出与近相机淡出。Bevy 使用反向深度，近处 NDC Z=1；应使用其视空间转换函数，不能直接抄旧 DirectX 样例的比较符号。Alpha blend 不进入该 prepass；还需验证 MSAA、深度清除值、裁剪和附加 pass 成本。[S9]
- **Hanabi 0.20.0 已有 Bevy 0.20 版本兼容依据**：固定标签 README/Cargo 明确匹配，支持 GPU 模拟、网格、flipbook、拖曳等；不能继续以旧缓存的 0.19 README 判断不兼容。其碰撞功能表仍未勾选形状和深度碰撞，本次没有核实其内置 soft particles/six-way，也未在本仓库编译或跑 GPU。将它列为性能需求出现后的候选，而不是画质升级的前置条件。[S10]

## 破口边缘提议：表面层次与真实轮廓分开处理

| 方案 | 能获得的细节 | 成本/限制 | 建议 |
| --- | --- | --- | --- |
| 断面边带材质：新鲜骨料、颜色/粗糙度变化、局部法线和缝隙暗部 | 中景的厚度、层次与材料对比 | 不改变真实轮廓；应由真实边界距离控制，避免给每个三角形画线或一圈均匀黑边 | 优先做 |
| 少量附着在暴露破口的棱角石片/局部闭合边带 | 近景的轮廓突起、掉角与阴影 | 必须贴合真实边/面，处理转角及重复覆盖；附加石片不能漂浮、堵门窗或只是遮住错误接缝 | 做小范围原型 |
| 离线生成共享的不规则切割面，重分两侧外表面 | 真实锯齿轮廓、断面起伏与匹配阴影 | 显示模型可能不凸，烘焙/布尔、三重交汇与导出验证成本高 | 作为高质量几何路线 |
| 只提高法线噪声或普通 POM | 断面内部的光照/视差 | 不应视为真实破口轮廓方案 | 保留微细节用途 |
| 所有碎块统一 bevel 或独立 displacement | 便于快速得到碎石外观 | 可能破坏完整建筑的咬合、出现提前裂缝；统一圆角也容易呈现磨圆/塑料感 | 不直接采用 |

### 接触面数据与暴露状态

建议逐步增加可寻址的表面数据，暂不在本记录中冻结字段名或升级格式：

- 稳定 patch ID、两侧 Chunk、标准法线、真实三角面/边界环；必要时保留局部厚度及与原外表面相交的 rim 边。
- Bond 是结构连接；同一 Bond 可能聚合多个接触补丁。它的中心、面积与二阶矩不足以重建每个补丁，不能把 Bond ID 直接当成唯一切面身份。
- 单侧暴露条件为 `alive(self) && !alive(neighbor)`；未破坏状态不在外表面显示损伤。没有邻块的原外表面或门窗边界不能误判成新破口。
- 同一 patch 可供材质边带、局部几何和 VFX 发射共用。状态放在建筑实例，不能修改共享 mesh/material 使另一栋同资产建筑也显损伤。
- 新增 chip/边带切面继续标为 fracture，保留所属 Chunk 的材料类别；原 exterior 的网格坐标和未损伤部分保持连续，不能让格线覆盖新鲜碎裂面。
- 现有 debug 边是整块折角，不等于真正洞口边。烘焙时保留内外表面交线更可靠；SideFX Boolean Fracture 也显式输出内/外表面及外部交线，并支持切割面属性传递。[S7]

低成本材质原型可先只处理自然暴露的 fracture 面，缓存它与 exterior 的交界；这不要求先完成整个新格式。若要让材质损伤跨到外表面、按邻块选择几何或从完整接触区域发射，再补 patch 身份和逐实例暴露状态。不要因此把所有细节工作都阻塞在格式大改上。

### 几何一致性与管线取舍

以下为本项目几何推论与实施约束：

1. **相邻接触界面共享同一空间曲面。** 两侧不能各自按法线施加同一标量噪声：`p+n*h` 和 `p-n*h` 是不同位置，会造成空隙或穿插。应由统一 patch/cutter 生成几何，两侧复用位置并反转绕序；多个切面交汇的边和角点同样要一致。
2. **边界零位移只能保持接缝，不能使该边界变锯齿。** 官方 Depth/Noise Ramp 的边缘衰减适合在保持原轮廓时增加内部起伏。[S6] 真正改变外轮廓，需要不规则切割面与两侧原外表面重新求交，或在破坏发生后局部替换闭合边带。
3. **不要为整个 Chunk 只准备一个统一破损版本。** 一个邻块删除后，其余接缝仍应完整；局部几何必须按受影响 patch 组合，并对相邻洞口合并/角点做确定处理。
4. **明确区分 reference physics 与 render detail。** 当前 `surfaces.py` 对显示网格仍检查凸性、体积和质心；`pipeline.py` 也拒绝未登记编辑/Modifier。不能简单插入 bevel/noise 后绕过检查。若保留原凸代理和质量，显示细节须使用原参考质心坐标，建立单独封闭性/自交/薄壁/最大偏差验证，并声明碰撞近似；若细节足以影响玩法，则同步重算物理/连接，而非继续宣称完全相同。
5. **微细节与轮廓细节分配不同尺度。** 首轮可试厘米级稀疏 chip 配合毫米级材质纹理，限制在局部厚度允许的范围；这是试调方向，不是已批准的通用振幅。细部增加后，仍要保留大尺度块面，而不是变成均匀高频毛刺。

## 建议交付顺序与验收

| 阶段 | 内容 | 主要依赖 | 验收重点 |
| --- | --- | --- | --- |
| A：先让动作成立 | 分层时序、材料/规模事件、异形共享碎屑、烟尘序列、反馈预算 | 现有 ECS；少量新视觉素材 | 单击及连击都能读到冲击→碎裂→消散，破口能及时看清 |
| B：融合环境 | Depth fade、近相机淡出、少量落地反弹、方向光；选择性加入涡动 | WESL、深度纹理；有限碰撞预算 | 贴墙不硬切、近看不穿帮、碎屑不持续穿楼板；测 CPU/GPU 增量 |
| C：破口边带 | 真实暴露区域/边界缓存、材质边带及少量局部几何 | patch/rim 语义及逐实例状态 | 关闭 VFX 后仍有边缘层次，完整建筑无提前露缝 |
| D：高质量轮廓 | 共享切割面、闭合细节几何、独立显示/代理验证 | 离线烘焙与格式扩展 | 近景斜视、逆光、薄墙、角点均成立，不靠烟尘遮错 |

先在一个带门窗的混凝土墙角做 A/B，保留现有无特效/旧效果基线、固定种子和同一相机路径。除截图外录制短回放：0.05 / 0.15 / 0.4 / 1 / 3s 的分阶段画面和连续运动才能检验重量感。

几何验收应关闭 VFX，覆盖正视、掠射、背光、内外两侧；检查完整状态、不同删块顺序到达同一最终状态、连续邻块删除、多个建筑实例、门窗通行和薄壁不刺穿。使用中近远三个视距检查边缘 LOD 和细纹闪烁。

性能验收记录实际分辨率、优化构建、CPU 更新/生成时间、GPU 透明绘制/深度预通道增量、可见粒子/主碎屑/边带三角形/材质实例数及连续点击峰值。当前只验证过数量有上限，不据此承诺 60fps，也不预设 GPU 粒子一定更快。[S3、S11]

## 采用的实施决策（2026-11-17）

### 破坏上下文与分层 VFX

- 保留原生 ECS，不引入 Hanabi。事件携带材料、删除体积、新暴露面积及真实接触三角面。烟尘与落灰按接触面面积取样，法线从存活侧指向已删除侧；即时粉爆与主碎屑使用命中点和命中法线，保留冲击中心。视觉强度不表示物理求解的冲量或质量守恒。
- 随机种子来自稳定资产名称和 Chunk ID，而非临时 ECS Entity；关闭边带、增加预热实体或调整生成顺序不会改变同一命中的粒子样式，便于同路径 A/B。
- 单次近景默认 64 个对象，分为即时粉爆 8、主碎屑 8、烟尘 24、落灰 24；后续层延迟出生。分别限额 96 / 96 / 320 / 128，总限额 640，包括尚未出生的对象。多次同帧命中公平分配即时粉爆额度，优先淘汰旧低优先烟尘；超过 96 个同帧位置时无法保证每个位置都保留独立粉爆。
- 默认出生延迟/存活时间分别为：粉爆 0 / 0.16–0.28s，主碎屑 0.04–0.16 / 2.0–2.7s，烟尘 0.08–0.26 / 1.4–2.5s，落灰 0.3–1.0 / 0.7–1.5s；完整单次生命周期至多 2.86s。
- 8 种共享不规则主碎屑网格，最大轴尺寸约 5–25cm。仅主碎屑执行 Avian 建筑球体扫掠，每帧最多 48 次；楼板、洞口和已移除代理都参与真实存活过滤，不使用虚构的无限地面。支撑块被删后，已停下的碎屑继续下落。
- 使用程序生成的 4 变体 × 8 帧烟尘图集，图集 512×256，每格 64px；不引入外部素材依赖。连续透明度、随机旋转、阻力与涡动配合环境/主光响应。材质句柄固定池化：544 个烟尘材质及 64 个碎屑淡出材质，另有 1 个透明预热材质。启动时提前准备烟尘及碎屑渲染管线，90 次更新后回收预热实体，避免首次短促效果在异步编译期间漏显。
- 相机采用 `DepthPrepass`、`Msaa::Off`；烟尘交界淡出距离 0.12m，近相机 0.08–0.3m 淡出。无深度预通道有独立 shader 分支，可用 `--no-soft-particles` 比较。尚未采用 six-way 光照。
- 距离和投影面积控制发射密度；投影估计考虑透视 FOV、宽高比、视空间深度及视锥，累计覆盖超过 45% 时降低新烟尘量。覆盖是可重叠的面积估计，不是 GPU 耗时。

### 真实暴露边缘与几何

- 在现有 GLB 的真实三角形上恢复接触补丁：对相邻块做反向共面三角形交集，保留分离区域，稳定编号，并核对面积。Bond 仍只表达结构连接，不使用它的二阶矩虚构接触多边形。
- 裁剪使用 double 精度及统一 Bond 平面，允许 40µm 共面误差；检查补丁面积与 Bond 的差异不超过 1% 或 0.00002m²。小于 `1e-7 m²` 的数值微接触仅从视觉缓存跳过：rectangle 4 处 / 合计 `6.86e-8m²`，l_shape 32 处 / `6.22e-7m²`，courtyard 7 处 / `8.35e-8m²`；原物理连接完整保留。
- 缓存按资产共享，暴露与损伤状态留在实例。仅 `alive(self) && !alive(neighbor)` 产生细节；完整建筑、原外表面以及没有被删邻块的门窗边不产生损伤。多个实例共享资产不共享损伤状态。
- 选择“暴露后增加局部闭合棱角边带”路线，不改完整建筑的咬合界面。边带沿真实接触面与原外表面交线生成，采用下方自然崩口修订的不等距轮廓、闭合三角截面和新鲜骨料材质；不沿三角化对角线画边。初版约 0.12m 周期的交替高低峰已由该修订取代。
- 最大边带深度 0.02m，且不超过局部最小面法向厚度的 8%；小于 1mm 的细节跳过。三角截面根部沿内向角平分方向嵌入存活块，顶部作最多 0.15mm 深度偏移，斜切处进一步受根部嵌入量限制，以避免共面闪烁和悬浮。新增几何标为 fracture，不覆盖外墙网格。
- 全场景边带限额 180,000 三角形，按稳定实例/块/补丁顺序选取，最终状态不依赖删块先后。每个存活块合并为一张边带网格，共享材料；距离超过 28m 隐藏、进入 24m 恢复。
- 接触面按存活块一次分桶；源边带按资产/补丁/存活侧惰性缓存，选定补丁不变时复用原实体与合并网格。显示预算不等于源缓存预算；源缓存受资产全部补丁数量限制，报告同时记录缓存与显示的三角形数。
- 加载时预先创建各材料类别的边带材质，并用相同 POSITION/NORMAL/COLOR、无 UV 的微小三角形预热对应渲染管线，90 次更新后回收预热实体；它不计入损伤或粒子预算。
- 原凸代理、质量、惯性、Bond 和文件格式不变。新增边带为有界的装饰几何，碰撞仍近似原轮廓；不把局部几何加层误称为完整共享切割面的重烘焙。离线不规则切割面、三重交汇布尔重建仍是后续高质量路线。

### 验证与未决问题

本次验证结果和实际运行参数见下方实施验证记录。调研资料核验已在原提议提交完成。尚未实施音效、视图震动、six-way、GPU 粒子迁移、动态刚体残骸或结构坍塌；这些不作为当前实现的完成声明。写实程度、被删质量的视觉比例及更多材料预设仍需后续美术调试。

### 优化构建性能记录（初版）

相同 RTX 4060 / Vulkan / 1920×1350 环境下串行运行矩形资产，关闭全部截图，固定模拟步长但以真实时钟采样，每组 710 次帧间隔。原始结果位于 `output/adr0008/performance/{full,baseline-clean,no-depth,no-detail}/report.json`。以下为单轮观测，包含首次破坏、近景移动、同帧多次破坏和消散阶段：

| 配置 | 实际帧间隔平均 / 最大（ms） | 深度预通道 GPU 平均（ms） | 透明通道 GPU 平均 / 最大（ms） |
| --- | --- | --- | --- |
| 全部开启 | 6.313 / 17.518 | 0.075（708 次） | 0.021 / 0.056（365 次） |
| 全部关闭：VFX / 边带 / 深度淡出 | 6.249 / 17.374 | 无 | 0.009 / 0.012（44 次，含启动预热） |
| 仅关闭深度淡出和预通道 | 6.293 / 18.644 | 无 | 0.015 / 0.036（365 次） |
| 仅关闭边带 | 6.334 / 13.395 | 0.055（708 次） | 0.024 / 0.065（364 次） |

- 全部开启的 VFX 生成 / 更新最大 CPU 时间约 0.131 / 0.092ms；连续破坏边带更新最大 3.037ms。三种资产的接触补丁缓存计算约 11.3 / 19.6 / 15.6ms，压力破坏边带更新最大约 3.13 / 5.00 / 6.32ms。
- 矩形投影烟尘覆盖峰值估计约 1.40 倍画面；该值累加重叠面片，不代表实际不透明像素比例。近景连续破坏触发密度降级；不能只以对象数量判断填充开销。
- 全部开启、关闭边带和关闭深度淡出的运行使用相同命中种子，生成数量与覆盖峰值完全一致。
- 各 GPU 通道单独记录，存在父子范围或不同有效采样数时不相加；未出现的通道不填造 0ms。关闭深度预通道也会改变不透明绘制的遮挡成本，不能把两种模式的总耗时差直接视为 soft-particle shader 自身成本。
- 帧间隔包含窗口呈现/同步及操作系统调度，既非纯 CPU 更新时间，也非固定模拟时间；平均值差异很小，单轮最大值有噪声。本轮不据此保证任意场景 60fps，也不以截图运行的数据做性能结论。

这些证据不代表已完成任意光照、所有内外侧掠射角或全部显卡的美术验收。薄墙与斜切的边界由自动几何回归覆盖；离线共享切割面、不同材料的进一步美术预设及广泛硬件性能仍未完成。

## 破口轮廓自然化修订（2026-11-17）

- 状态：已采用；实现与本节验证记录对应。上方初版图像、数量和性能结果保留为历史，不作为修订后的测量值。
- 背景：用户反馈闭合锯齿边过于规则。初版即使随机改变幅度，仍以约 6cm 等距采样并严格交替高低峰，形成明显的机械齿列。
- 决策：取消等距/奇偶节拍。采用 1–3 个成簇的角状崩口，混合 8.5–28cm 宽破口、少量 3.5–7.5cm 细小掉角、不对称肩部及 2.5–12cm 平缓间隔；轮廓不要求每个低点后立即出现高点。宽破口保持较高的不规则肩部，避免去掉齿列后反而近似整齐切口。宽度与埋深分别由独立的缓慢随机变化控制，空间变化跨度为 15–42cm / 22–55cm，避免仍然呈现同一截面沿直线挤出的效果。
- 参数：凸出高度仍限制为 0–1 倍原安全深度；边带根部宽度为安全深度的 0.8–2.2 倍，嵌入量为 0.16–0.4 倍。端点高度归零，沿线折点最小间距 12mm；按实际轮廓、宽度和埋深偏差简化，点数至多 `ceil(28 × 边长米数) + 2`。闭合拓扑、20mm / 局部厚度 8% 限制、逐截面的斜切安全偏移、实例隔离及全场景 180,000 显示三角形限额继续适用。
- 确定性：以 patch ID 和规范方向的端点生成种子；反向遍历仍得到相同空间轮廓，删块顺序不改变形状。
- 备选与取舍：仅随机化齿高会保留固定周期；等距白噪声容易形成另一种均匀毛刺；平滑正弦容易像波纹。采用有平缓段的多尺度角状轮廓，保持有棱角的材料破碎感；本次没有增加截面顶点、位移贴图或离线重切资产。
- 验证要求：检查不等距、连续肩部与平缓段；回归闭合性、薄墙/斜切不刺穿、方向反转一致、删除顺序与实例隔离。在相同相机路径下关闭 VFX 对比修改前后近景，并检查三种资产连续破坏的数量和更新开销。
- 已完成验证：38 项测试、格式检查、严格 Clippy 和优化构建通过。新增 4 项轮廓回归覆盖方向反转一致、空间间距/尺寸上限、非周期肩部和平缓段，以及跨种子的可见崩口覆盖，防止去掉规律锯齿后变得近似平切。既有闭合、薄壁、斜切、实例和删除顺序回归全部通过。
- 引擎对比：旧版保存在 `output/rim-irregular/before`，新版三种资产在 `output/rim-irregular/improved/{rectangle,l_shape,courtyard}`；全部关闭 VFX，以相同路径保存每种 12 张截图和无错误报告。矩形近景左右对照图为 `output/rim-irregular/comparison.png`（左旧、右新）；检查不再呈现等距齿列，保留不均匀的宽肩崩角和细碎段。
- 数量与开销：连续破坏结束后，三种资产的显示三角形分别为 19,370 / 29,818 / 38,538，均低于 180,000 上限，且低于初版的 20,738 / 32,404 / 41,430。矩形另以无 VFX、无截图的优化构建单独测量（`output/rim-irregular/profile/report.json`）：边带更新最大约 3.261ms，710 次实际帧间隔平均 6.249ms；这些为本机单轮观测，不是任意硬件帧率保证。
- 验证边界：此次修订只改变附加边带的局部轮廓和截面变化，完整切面与凸代理继续沿用原资产；没有完成离线共享不规则切割面或大范围掉角重建。
