# ADR 0024：独立新撞击事件的一次性当前簇绑定

## 状态

- 已采用并实现；独立夹具回归通过。
- 日期：2026-11-17。
- 补充 [ADR 0017](0017-progressive-impact-unloading.md)。已求解事件的分离卸载规则保持不变；本记录不宣称修复新版楼体落地后主簇基本完整的问题。

## 背景

物理接触发生后，Avian 已经向刚体施加接触冲量。结构分析按固定步预算排队，因此同一原簇上可能同时存在两种工作：从未开始结构求解的独立真实接触事件，以及已经求解、正在等待当前图上进一步断裂的旧事件延续。

原来的成员检查把二者一律视为已经卸载的旧父簇事件。如果另一个裂缝先移走一个无关成员，即使某个独立新事件的全部实际受载块仍位于同一个当前子簇，它也会在首次分析前被删除。

相反，已经求解的父簇响应不能在拆分后重新把原始冲量交给更小的子簇。ADR 0017 已验证这种重注入会导致逐步清空连接。

## 决策

- 用 `ClusterImpact.prepared` 区分生命周期。`None` 表示从未构造、求解过结构载荷工况；存在缓存表示该事件已经开始分析。
- 只允许从未求解的新事件检查其实际 `loads` 键：所有受载块必须仍存活，并属于同一个当前动态、未锚定刚体；该刚体须属于同一建筑。
- 当前子簇成员必须完全包含在原事件成员集合中，所有受载块都须包含在该子簇。禁止将事件扩展到新合并的无关成员。
- 满足上述条件时，使用当前子簇的精确成员建立一次惯性平衡工况。原始逐块接触冲量保持不变，不跨多个子簇分配，不向 Avian 再施加物理冲量。
- 首次求解后即进入已准备状态。其延续遇到后续拆分仍按 ADR 0017 结束；成员死亡则作废。即使所有受载块仍在某个子簇，也不能重新准备已求解事件。
- 新事件的受载块跨多个当前刚体时结束事件；受载块死亡或成员关系无效时作废。没有内部连接的单块不生成结构分析。
- 新增 `rebound_fresh_structural_events` 诊断计数，区分首次绑定当前子簇与已求解事件的分离释放。
- 不改变材料参数、10 ms 标定、2 m/s 门槛、求解容差、逐步断裂预算或刚体速度。

## 验证

自包含的三块自由梁在另一个连接先断裂后形成 `2+1` 分量：

1. 尚未求解、受载点位于两块分量中的独立事件，得到与直接针对该当前分量求解完全相同的断裂选择、承载率和载荷平衡比；规范点反力检查通过，刚体速度不变。
2. 该事件只记录一次新绑定；首次求解后的延续再次遇到拆分时直接释放，不产生第二次绑定或候选队列。
3. 尚未求解的事件如果两个受载点分居裂缝两侧，则不求解、不改变连接、不向子簇分发冲量。
4. 原有“已求解父事件拆分后释放”及采样开关不影响断裂选择的回归保持通过。

`cargo +1.99.1 test projectiles::tests -- --nocapture` 的实际结果为 **10 通过、1 失败**，测试部分 `5.95 s`。唯一失败仍是新版真实楼体落地的主簇破坏程度要求，不能将本次独立事件修正记为该失败的修复。

## 历史落地诊断与限制

局部接触发现修复前、采用 20 µm 策略的历史 `highrise_slab`，资产 ID 为 `94ea5ea08a1e92a9d9f7839585648fc2402d88af04c27d5f3f890a22f3195f3a`。上部 118 块、约 771.6 t 的真实落地回归在新事件绑定修正前后均断开 18 个连接、释放 3 个已经准备的事件，留下 `[116,1,1]`，本次新绑定计数为 0。

测试可通过 `DESTRUCTION_LANDING_TRACE=1` 打开只读诊断。它在窄相位之后、求解器之前，用当前线速度、角速度、质心及接触点计算接近速度，同时记录断键、面片面积、逐事件受载块、准备状态和刚体运动。

该场景首次接触时，完整刚体以约 `18.97 m/s` 下落，第一次物理响应已使整个 118 块刚体的竖直速度变为约 `-1.89 m/s`，此时只断开一个结构连接。第 15 个断键、首次分离发生时，剩余 117 块主簇已向上运动。所有断键位于最低层的源高度 `16.12–16.24 m`。独立的另一接触事件此前已多次求解，因此必须遵守旧事件释放规则，不能用本次新事件绑定规则保留它。

Avian 0.8.0 对新流形会计算包括角速度的 `normal_speed`；接触回收路径只更新分离量并提前返回，可以保留过去的速度。因此没有用该旧值重新触发持续接触。当前轨迹中确实被接触对门控抑制的高速点均属于已经分离的单块，尚未发现它直接抑制主簇再次撞击的证据。

## 备选方案与取舍

- 一律丢弃任何原成员发生变化的事件，能避免旧场误用，却错误取消尚未求解的独立接触。
- 将所有已求解事件按新子簇重分组，会恢复 ADR 0017 记录的父冲量反复使用问题，本次不采用。
- 提高强度、延长冲击标定时间、限制最终碎块数，不能解释独立事件的生命周期错误，也不能修复刚体接触与断裂之间的时序问题，本次不采用。

## 因果独立事件的隔离试验

以下试验已明确不采用，原型标记、钩子、断键历史字段和因果重平衡分支已从 `src/` 移除。试验提议为：每个已经准备的事件记录自己实际提交的断键历史；若其下一个所选断键会使当前簇分离，则该事件随断键提交立即结束。其它事件造成的拆分，只在所有真实受载源仍属于唯一当前子簇、原成员均存活，而且本事件全部历史断键都没有跨最终分量时，才在该子簇重新构造平衡工况。缺失历史、受载源跨分量、成员被点击移除或包含原事件之外的新成员时保守结束。

试验使用测试 App 专有标记，未改变正常应用规则。冻结输入为局部接触发现修复之前、仅审计元数据不同而接触几何相同的历史 `f2dd9aad64b05a115de8ed25ecb8997793a5bb4ba5852560b3f25ae5513f66e5` 快照，保存于 `output/diagnostics/causal-landing-snapshot.destruction.json`。与基线相比，试验实际保留并重平衡独立 B 一次，得到 22 次求解、21 个断键和 `[115,1,1,1]`；增加的碎块仍是最低层单块楼板，没有达到原测试要求的多块楼板与墙体分组或远离接触层的内部断裂。原严格落地测试仍失败，因此拒绝将该提议作为生产修复，没有修改验收门槛。

首次 B 在 A 造成分离后只失去约 1.27% 的非源质量，但相同虚拟冲量在更小惯性量下可产生更大响应。唯一子簇与因果历史检查能防止跨多个子簇分发冲量，不能单独证明裂纹耗能或瞬态应力波的能量正确；不能仅以剥落块数略有增加代替真正的碰撞/断裂耦合。试验日志为 `output/diagnostics/causal-upper-landing-trial1.log`，对应源快照和补丁保存在 `output/diagnostics/causal-trial1-source/`。

最终生产 `highrise_slab` 为 `4e05bcd6cd187cacf83a7f6683e29d08449233bc9e1f915061a47bbebebafbed`，其有限接触域判定修复改变了部分接触面片。移除未采用原型后，最终统一 `cargo +1.99.1 test -- --nocapture` 为 **114 通过、1 失败、0 忽略**，测试部分 `7.84 s`。唯一失败仍是原严格落地程度要求：18 次动态求解、18 个断键、3 个已准备事件释放、无排队，最终 `[116,1,1]`；没有修改门槛或把失败标成忽略。其余 10 项撞击回归（含新鲜事件绑定、源跨分量释放、已有父事件卸载、强弱落差、载荷平衡和采样不改变结果）通过。日志为 `output/diagnostics/final-v2-all-tests.log`。

最终正常程序构建、`clippy --all-targets -- -D warnings` 和 `fmt --check` 均通过。此结果确认本次生命周期修复及目录/API 迁移可以编译并通过其聚焦要求，不能据此声称大块落地耦合已修好。

## 未决问题

新版大块落地的主要限制仍涉及整簇刚体先完成碰撞响应、结构断裂随后逐步处理的耦合。进一步改善必须继续保留动量、载荷平衡和卸载证据，不能把已经求解的父事件当成新的子簇冲量。本记录不引入瞬态应力波、裂纹耗能或新的碰撞速度触发规则。
