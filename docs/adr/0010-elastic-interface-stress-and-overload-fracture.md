# ADR 0010：六自由度界面应力、自重承载与过载断裂

## 状态

- 已采用，首轮实现与已完成验证分别记录于下文。
- 日期：2026-11-17。
- 采用 [ADR 0003](0003-structural-loads-and-progressive-fracture.md) 的六自由度小变形连接图方向；明确本轮构成关系、求解器、失效规则与范围，不声称完整 FEM 或工程安全分析。
- 后续 [ADR 0016](0016-damaged-structure-solver-and-support-release.md) 修正困难受损图的数值路径及无效 HUD。下述原分块 Jacobi 策略和首轮验收保留为历史；当前对困难图增加稀疏因子与补偿残差修正，精度目标和物理模型保持。

## 背景

ADR 0009 仅按连接图和地基锚点决定静态/动态簇，不能判断仍连着地基的悬臂或细支撑是否承载不足。资产已经提供密度、质量、弹性模量、泊松比、拉压剪强度、接触面积及未归一化面积二阶矩，足以实现可审计的线弹性界面网络原型。

## 已采用的决策

### 节点、连接与边界条件

每个 Chunk 的未知量为质心处三维平移 `u` 和小转角 `theta`。固定 Anchor 锁定该节点全部六个自由度；仅求解仍有固定 Anchor 的连通分量。脱离地基的动态簇不接受静态自重求解，接触和休眠不生成结构 Anchor。

连接界面中心为 `p`，端点质心为 `c_a,c_b`，界面位移跳跃和相对转角为：

```text
d = (u_b + theta_b × (p-c_b)) - (u_a + theta_a × (p-c_a))
phi = theta_b - theta_a
```

用此共同界面点计算力臂，使整体刚性平移、转动不产生虚假连接应变。各 Chunk 自重 `m*g` 作用于其质心，外加载荷用同一坐标系中的质心力和力矩表示。运行时将世界重力转到建筑局部坐标；多个实例独立保存状态。

### 构成关系与物理单位

对单位法线 `n`，`P=1-n*n^T`。资产 `Q=integral((x-p)(x-p)^T dA)` 单位为 m⁴，投影得到 `Qp=P*Q*P`；`C` 表示 `n×` 的反对称矩阵，`B=C*Qp*C^T`。

```text
L = |p-c_a| + |p-c_b|
G_i = E_i / (2*(1+nu_i))
E = harmonic_mean(E_a,E_b), G = harmonic_mean(G_a,G_b)
K_translation = (A/L)*(E*n*n^T + G*P)
K_rotation = (E*B + G*trace(Qp)*n*n^T)/L
energy = (d^T*K_translation*d + phi^T*K_rotation*phi)/2
```

这是传递界面力与力矩的弹性连接近似，不是完整梁单元或连续体。几何任意形状时的等效长度、各向同性、极惯性扭转和材料参数仍是明确近似。保留完整切平面二阶矩，不用单个半径抹平截面方向性。

### 稀疏求解与错误处理

- 以 f64 组装确定性 6×6 分块稀疏矩阵，消去固定自由度；旋转未知量以模型特征长度缩放，减少平移/转动单位差异。
- 使用分块 Jacobi 预条件共轭梯度，默认相对残差目标 `1e-8`、最多 3000 次迭代；小图在测试中与独立稠密 Cholesky 参考解比较。
- 返回界面力/力矩、支撑反力/反力矩、诊断位移、迭代次数与实际残差。运行时另外计算总力/总力矩平衡误差和最大平移估计，不把固定模拟 dt 当作求解耗时。
- 无支撑路径、退化截面、非正定预条件块、数值失败和未收敛均返回明确错误，不增加虚构刚度、隐藏锚点或把失败解释为零应力。
- 失败分量的当前应力无效，停止其应力驱动断裂，其他有效分量、直接点击伤害和已确定拓扑仍继续。失败保留诊断，每个模拟秒重试一次；拓扑/配置变化会立即触发新求解。

### 应力恢复与失效判据

界面合力与力矩按法向、切向、弯曲和扭转分解。法向应力由轴力与完整截面弯曲分布组合；切应力使用直接剪切与极惯性扭转近似。运行时使用真实 ContactPatch 三角形顶点计算截面应力极值，并以 `section_exact` 区分几何截面输入与缺失时的等二阶矩椭圆近似；后者不是任意多边形的保守包络。

强度取两端材料对应拉、压、剪限值的较小值。承载率为拉应力/抗拉、压应力/抗压、剪应力/抗剪三者最大值，超过 1 表示此模型下超载。界面力单位 N、力矩 Nm、应力 Pa，损伤无量纲。

### 固定步损伤与拓扑提交

默认启用自重和过载断裂；固定 60 Hz 更新，持续过载：

```text
damage += dt * max(utilization-1,0) / 0.5 seconds
eligible = damage >= 1 OR utilization >= 4
```

每栋建筑每固定步最多断开 4 个连接，按承载率降序、稳定 Bond ID 次序选取。每步只积分一次 `dt`；本步断裂后的载荷重分配在下一个固定步求解，不在同一步每次重算重复积分时间。预算外的已积累损伤保留。

在 `FixedPostUpdate` 先更新应力/损伤，再执行 ADR 0009 簇重建，最后交给 Avian 物理。连接断开不删除两侧 Chunk，失去锚点的分量才转动态；暴露边带和烟尘沿用现有表现系统。

按存活 Chunk、连接状态、资产、局部重力、外加载荷和数值求解设置缓存结果。完整建筑不每帧重新求解；拓扑变化后重新求解整个受影响建筑中的锚定分量。未实现跨多帧后台求解，调试构建的大图重算仍可能造成帧停顿。

## 已实现与验证

- `src/stress.rs`：界面模型、稀疏组装、预条件求解、真实截面应力与反力恢复。
- `src/stress_runtime.rs`：按实例缓存、诊断、固定步损伤、预算断键、失败重试与动态分量排除。
- `src/stress_smoke.rs`：真实自重求解后，使用明确质量与几何的双柱混凝土梁验证支撑移除、仍连通时的过载、自动断键、下落和休眠，并验证刚性撞击物。
- 纯求解测试已覆盖悬臂力/力矩、截面应力、闭环稠密参考解、对称与不同刚度路径分担、移除路径后的重分配、刚体零应变、遍历顺序、无效输入及未收敛。
- 本阶段完整 Rust 验证已通过 `cargo test`：65 项通过、0 项失败；`cargo clippy --all-targets -- -D warnings` 和 `cargo fmt --check` 均通过。Blender 资产与接触精度相关 28 项测试通过。后续新增验证见 ADR 0013 至 0015。
- 六种资产的完整自重均收敛且承载率低于 1。图形验收通过 `--scene <name> --stress-smoke-test output/acceptance/stress-<name>` 检查实际资产、下述持续过载梁及两种有限质量刚性撞击物；每次保存 7 张阶段截图和一份报告。
- 六种场景的最终图形路径均通过：各报告 `errors=[]`，完整自重求解有效且相对残差不超过 `1e-8`；持续过载、自动断键、下落、休眠，以及球/方块真实碰撞后触发断裂且保持自身完整并改变速度的检查均通过。每条路径运行 1000 个验证帧，均生成 7 张阶段截图。

## 备选方案与取舍

- 最短路径或树上累计重量无法一致处理闭环和刚度不同的多支撑，本轮使用全分量弹性平衡。
- 为每个 Chunk 建物理关节会混合结构承载与接触求解，完整建筑成本更高；物理仍以刚体簇表示。
- 每帧稠密求解易于检查但不适合几千自由度，仅保留为小图参考。
- 质量代理、弹簧刚度补丁、反复重置基准载荷会掩盖真实错误；本轮不采用完好 baseline 或应力归零机制。

## 未决问题与范围

- 未实现大变形、屈曲、可见挠曲、各向异性木材、钢筋/钢接头专用模型或工程安全保证。
- 本记录首轮未实现动态内部载荷；后续 [ADR 0014](0014-inertial-cluster-impact-fracture.md) 已补充动态多块簇撞击的惯性平衡连接求解。完整瞬态应力波和接触支撑反馈仍未实现；静态建筑的局部冲量路径保留 [ADR 0011](0011-building-catalog-and-rigid-impact-scenarios.md) 的标定边界。
- 分量结果缓存和连续稀疏存储已在 [ADR 0015](0015-structural-and-collision-runtime-performance.md) 实现并记录测量；异步求解、长期损伤/疲劳、断裂能与材料玩法标定仍需后续验证。
- 资产制作中低于几何精度的线状接触已按 [ADR 0012](0012-resolvable-contact-sections.md) 排除；求解器仍拒绝真正退化或不可解的有效输入。
