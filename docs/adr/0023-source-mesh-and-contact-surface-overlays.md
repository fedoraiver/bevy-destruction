# ADR 0023：保留源碎块网格与真实接触面的断面显示

## 状态

- 日期：2026-11-17。
- 已采用并实现；六资产最终接触校验已通过，图形检查的快照与范围见下文。
- 独立共面显示层的渲染决定已由 [ADR 0025](0025-single-owner-fracture-surface-shading.md) 替代：移动视角的浮点深度竞争会使断面与 grid 闪烁，现使用源三角形单次片元着色。保留源网格、规范接触及物理职责的原则继续有效；下述显示层实现和验收属于历史。
- 补充 ADR 0020，替代其制作端对部分接触面进行实体网格材质分割的实现路径；多面片物理、质量、碰撞和 v2-only 约定保持。

## 背景

六个场景的不规则源碎块及复合凸代理已经分别通过封闭性、凸性、体积、质心、完整惯性和尺寸检查。阻塞正式发布的是显示材质的部分接触分区：大量不同浮点平面投影和交点舍入会在极小条带处形成无法稳定嵌入 float32 的扇区。即使单个修复样例通过，完整矩形仍会丢失原有屋顶角点。

真实几何和物理接口不需要为了改变颜色而重新切割。v2 已保存经过验证的规范接触多边形，可以直接承担断面材质的显示区域定义。

## 决策

- GLB 保留已验证的源 Chunk 网格，材质分类不得移动顶点或改变面与拓扑。只有被真实接触完全覆盖的源面才可整体标为 `fracture`；部分接触的源面保持其原材质。
- 运行时由规范 ContactPatch 多边形生成断面显示层。按 Chunk 合并三角形，每个 Chunk 最多一个额外网格；两侧采用相反绕序和法线。
- 显示层从实例化时即挂在所属 Chunk 下。完整实体内部自然遮挡这些接触面；邻块删除或结构分离后，已有显示层随所属刚体显露和运动。实例化后不需要逐帧切割或重新分类。
- 断面显示层使用既有物理材料对应的粗糙材质，采用 StandardMaterial 的 `depth_bias=+2` 处理共面深度；顶点不做位置偏移。正偏置的含义核对了本机构建所用 Bevy 源码。
- 显示层不参与碰撞、拾取源三角形、体积、质量、惯性、接触覆盖验证或应力求解，也不投射额外阴影。原实体承担这些职责。
- `--no-detail` 仅控制可选的立体破口边带，真实接触面的材质显示独立保留。
- 显示网格按资产/Chunk 缓存，材质按物理类别复用；多个实例共享数据，位姿与可见性由 Chunk 父子关系处理。
- 全部资产只使用当前 v2 数据，不提供旧格式、旧材质名或缺失接触面的回退。

## 备选方案与取舍

- 继续对全部材料区域做共形显示网格细分：可以直接烘焙完整材质区，但本轮多次完整试装仍因微小交点和尖角失败，没有采用未通过的试验代码。
- 提高焊接、角点位移或面积误差容差：会削弱源几何保留约束，未采用。
- 只把整面标成断面材质：部分覆盖时会污染真实外表面，未采用。
- 断面显示层增加少量可缓存的渲染几何和绘制工作，换取原几何完全保留及更直接的制作流程。此开销需在真实场景验证，不能以未测量的性能推断代替验收。

## 验证要求

- 制作前后源顶点、面与质量属性不变；门窗和原外轮廓保持，复合碰撞与物理面片继续按原严格门槛验收。
- 显示层覆盖面积等于规范面片，两侧绕序、法线、局部坐标与随物体运动的材质正确，没有位置偏移或跨洞口凸包。
- 显示层不改变物理/拾取三角形或刚体质量；删除 Chunk 后子层隐藏，多个实例共享网格和材料。
- 真实 GPU 图像检查完整建筑、部分破坏与运动后的材质，确认深度偏置没有提前显裂缝或产生闪烁。
- 六个正式场景完成清单/GLB 校验、自重和破坏验收；受力视图独立完成实际图形检查。

## 已完成验证

- `contact_` 聚焦的 9 项 Rust 回归通过：面积、精确顶点、两侧绕序/法线、深度偏置、局部坐标、缓存复用/失效、父子运动与隐藏、`--no-detail` 仍保留断面、无碰撞和拾取身份。
- 接触覆盖改为先裁到有限的真实面片，再测其与源三角形平面的距离。未改变 `40 µm` 距离门槛，新增大三角形上的微小倾斜面片及真实离面负例；13 项接触/破口聚焦回归通过。
- 已查看 `output/acceptance/natural-collapse-final/01-intact-rectangle.png`、`03-bulk-tipping.png` 和 `04-final-collapse.png`：完整矩形楼没有提前显露内部裂缝，倾倒后断面显示随碎块运动，原窗洞及外轮廓保留。该次倾倒数值报告的接触采样漏检另行修复，不能将它记录为完整验收通过。
- 首轮受力图的基准场景尚未显示，该次报告不计入通过；补截图有效性门槛后的复验见下文。先前局部 CDT 试验的通过同样不计为本方案的整体验收。
- 最终六场景的清单/哈希/材质角色、自重平衡及实际 GLB 接触覆盖全部通过，未放宽容差。采用 ADR 0020 的最终资产 ID：合并后显示接触面数量为矩形 2836、L 形 4679、庭院 5214、板楼 2964、L 高楼 2741、桥 678，共 19112；26524 个原始承载面片全部验证，父连接面积最大差不超过 `3.6e-7 m²`。
- L 形楼唯一超出相对覆盖门槛的 `63 µm` 面片已在制作端按实际 GLB 轮廓内移一个顶点 `0.954 µm`，两端覆盖误差约 `1e-13`；源网格与碰撞体没有变化。该修正和源几何保留分别验证。
- 具有真实场景像素门槛的受力图复验已通过，使用局部漏接触修复前的矩形快照 `2f6e82d2f68567ead7d70ee6753cb6876c153ca95666d345f56b1425c67fe786`。输出 `output/acceptance/natural-force-readback-final` 五张有效画面，主程序实际显示与清空已检查；基准捕获拒绝了 1 张空场景后重试成功，见 ADR 0021。最终目录修复后的图形结果另行记录，避免混用身份。
- 最终矩形资产 `28d80db4...68fee` 执行 `--smoke-test output/acceptance/natural-irregular-rectangle-final --no-vfx`，退出码 0、`errors=[]`，首击移除 3 块，第二实例/相机/连续破坏/回收检查通过。已检查实际破口及近景，粗糙断面没有污染其余外墙；首次通用网格截图仍早于显示管线就绪，该图片不作为完整建筑基准。
- 同一最终矩形快照再次运行 `--force-smoke-test output/acceptance/natural-force-published` 和 `--collapse-smoke-test output/acceptance/natural-collapse-published`，均退出 0、`errors=[]`。受力图的完整建筑基准、断键/真实冲量/清空五阶段均复核；倾倒保留上部 91 块、下降 `3.08838 m`、倾斜 `3.14001 rad`，准确记录与上方静态支撑 `0005` 的正冲量，2 条静态强度断键、0 次求解失败，质量和有限状态检查通过。
- 正式高楼的严格落地破坏程度仍有独立失败，见 ADR 0024；上述显示、自重和矩形倾倒验收不能替代该回归。

## 未决问题与来源

源为本仓库已验证的 Chunk/ContactPatch 数据及 Bevy StandardMaterial 深度偏置实现。后续若扩展多个显示层、透明材料或极大坐标场景，需要重新检查排序、深度精度与渲染成本。
