# ADR 0015：结构求解、缓存与碎片碰撞性能

## 状态

- 已采用并实现；求解、物理依赖对比、完整测试和下述图形验收已完成。
- 日期：2026-11-17。

## 背景

高楼的六自由度求解和落地后大量独立刚体接触会阻塞主线程。默认开发构建中，455 块板楼一次完整自重求解约 357 ms；不能通过减少碎块、降低收敛精度或关闭破坏来替代性能改进。

## 决策

- 装配时仍按稳定节点/连接顺序累积稀疏块矩阵，随后一次转换为连续块 CSR。PCG 使用连续行遍历，矩阵乘法、预条件与残差缓冲区重复使用，避免每轮分配及树节点遍历。
- 保留 f64、小变形界面模型、默认相对残差 `1e-8`、迭代上限和损伤判据。性能改动不更改材料强度或撞击标定时间。
- 默认开发构建仅优化本项目、Avian 和 Parry 到 `opt-level=2`，保留调试信息和开发断言。没有启用全依赖优化，也没有要求用户使用 release 才能运行演示。
- 应力状态留在原 ECS 实体上，用值交换暂存，避免每个固定步增删组件引发实体迁移。
- 用实例、载荷、求解设置的变更版本及建筑坐标下重力判定输入是否变化。未变化时复用键和健康结果，不每步扫描所有 Chunk、Bond 或健康损伤项；仍持续处理过载和待断连接。只修改即时断裂阈值时刷新损伤更新资格而不重算内力，保留低于 1 的自定义阈值语义。
- 按锚定连通分量缓存有效求解。动态残骸变化时，未改变的底部结构复用原解；载荷、重力、求解设置、分量成员或内部连接变化时重新计算。失败结果不加入分量缓存，原失败重试机制保留。
- 刚体簇重建时先识别可保留的原簇，仅对新簇重新汇总质量属性；移除每个 Chunk 重挂父实体时的冗余显式刷新，旧刚体销毁前的统一刷新保留。
- 动态撞击每固定步最多求解一个簇，排队过程及有效性检查见 [ADR 0014](0014-inertial-cluster-impact-fracture.md)。这限制单步求解数量，不声称限制最坏情况下的单次求解耗时。

## 备选方案与取舍

- 降低精度或碎块数量会改变结果；本轮不采用。
- 全依赖优化增加首次编译成本，先只优化已测得的求解和碰撞热点。针对依赖的优化同样增加首次构建时间，应同时记录收益和构建成本。
- 异步求解需要处理输入过期、任务取消和断裂反馈时序，本轮保持同步顺序与确定的断裂预算。
- 分量缓存增加少量连接 ID、报告和键的存储；不缓存整个稀疏矩阵。资产清单在实例加载后保持不变，资产重新实例化时缓存随实例释放。

## 已完成测量与验证边界

- 相同资产与精度，板楼初始求解从约 `356.7 ms` 降到 `29–30 ms`，L 形高楼从约 `283.9 ms` 降到 `26–27 ms`，桥梁从约 `24.4 ms` 降到 `2.4–3.2 ms`。对应迭代数仍为 `449 / 386 / 188`。这是当前机器开发构建的单次 CPU 求解测量，不是画面帧率。
- 单独隔离 CSR/缓冲复用、保持未优化构建时，板楼 PCG 约 `279 → 227 ms`，L 楼约 `229 → 189 ms`；包含装配及恢复的总耗时约减少 `13–15%`。其余收益主要来自针对本项目的开发优化。
- 真实板楼上半部分自由落体并破碎的相同 300 固定步测试，物理依赖优化前后均通过；测试进程内用时从 `10.04 s` 降到 `2.30 s`，约加速 `4.37` 倍、减少 `77.1%`。包含初始化与断言，不是渲染 FPS。首次针对性重编译耗时 `4 分 51 秒`，编译了 Parry、Avian 及本项目，没有广泛重编译 Bevy。
- 缓存回归通过：120 个健康固定步复用原结果；外载、重力、容差、支撑变化正确失效；独立残骸移除不重算未改变的锚定分量，再改变载荷则重算；冷启动和缓存预热后降低即时阈值均在下一固定步断裂，后者不额外数值求解。
- 最终 `cargo test`：75 项通过、0 失败、0 忽略；测试部分共 `2.60 s`。`cargo clippy --all-targets -- -D warnings`、`cargo fmt --check` 通过。
- 实际板楼落地路径报告 `errors=[]`、内部楼层断裂、质量保留且数值有限；最终 227 块形成独立残骸，详见 [ADR 0014](0014-inertial-cluster-impact-fracture.md)。矩形场景完整 1000 帧应力/刚性撞击回归也通过，`output/acceptance/runtime-stress-rectangle/report.json` 的自重、渐进断裂、下落休眠、球与方块碰撞及反作用检查通过，7 张阶段图完整。
- 最终构建另执行 L 形高楼的 `--landing-smoke-test output/acceptance/landing-highrise_l --profile`，关闭截图，报告 `errors=[]`。450 个墙钟帧间隔样本平均 `76.91 ms`、最大 `240.58 ms`，包含自由落体、断裂、烟尘、渲染和大量接触的混合阶段；它不是纯物理耗时，没有同路径旧版本画面对照，不据此计算加速比。最长动态结构求解 `28.44 ms`。此场景仍有明显长帧，当前开发构建尚未达到稳定 60fps。

## 未决问题

大量凸接触、边带生成和单次大图求解仍可能出现长帧。后续是否需要分层破碎、接触预算、矩阵增量更新和异步求解，应依据实际帧时间继续测量。

本仓库求解器、真实资产测试、固定步落地回归及锁定版本的本地 Avian/Parry 实现。
