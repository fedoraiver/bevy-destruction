# ADR 0013：随碎块运动的程序化网格与断面材质

## 状态

- 已采用、已实现并完成下述验证。
- 日期：2026-11-17。

## 背景

原着色器用世界位置和恒等的 `building_from_world` 采样网格、骨料和孔隙。动态碎块平移或旋转后，采样位置随世界变化，导致图案相对物体滑动。每块单独使用局部位置又会丢失相邻预破碎块之间的相位连续性。

## 决策

- 将顶点的不可变建筑初始坐标编码到 UV0.xy、UV1.x，保留米制尺度和跨 Chunk 相位。运行时模型变换只改变显示位姿，不改采样坐标。
- ADR 0025 在 UV1.y 增加每三角形的接触候选索引；UV0.xy/UV1.x 的米制坐标语义保持。索引随原三角形携带，不使用世界锁定坐标重新采样。
- 普通导入网格按其源 Chunk 变换烘焙；新增破口边带在转换到 Chunk 局部网格时采用同一坐标约定。
- 沿用 Bevy 0.20 标准顶点、深度和实例化管线。片元阶段从插值坐标导数恢复原始表面方向，并将断面微法线扰动映射到当前世界方向，不逐帧复制材质或上传每块逆矩阵。
- 派生网格按源 Mesh 标识和初始变换缓存，多实例共享；源 Mesh 卸载时移除缓存强引用。仍被显示实体引用的派生网格正常存活。
- 当前资产原本无 UV 贴图，两个 UV 通道用于程序化坐标；本决策不声明支持保留任意外部模型的已有 UV 纹理方案。

## 备选方案与取舍

- 世界投影不能满足运动残骸的图案附着。
- 每帧更新每块材质矩阵增加材质实例和上传成本，也容易在多实例之间串扰。
- 自定义顶点管线可携带独立属性，但需要同步维护前向、预通道和实例化接口。本轮复用现有插值通道，代价是每个源显示网格多一份带坐标的派生网格。

## 验证要求与已完成验证

- CPU 材质测试验证相邻 Chunk 坐标连续、源 Mesh 不被修改、相同源/变换复用缓存、非恒等源变换及边带转换。
- 实际 AssetPlugin 生命周期测试验证源卸载后，闲置派生网格释放，存活 Mesh3d 的网格保留。
- `--material-smoke-test output/acceptance/material-attached` 以真实 BuildingMaterial 渲染两块相邻网格和断面，物体、相机及主光同时平移/旋转，读取 512×256 离屏图像作比较。
- 最终报告 `errors=[]`：平移平均 RGB 误差为 `0`，旋转约 `0.00001017`（0–255 通道值）；变化像素比例均为 `0`。正例允许平均误差 `0.75`、变化像素比例 `2%`。
- 世界锁定负对照平均误差 `2.8544`、变化像素 `3.7338%`，明确超过正例门槛；四张截图已检查，避免空白渲染造成假通过。
- 默认前向与深度管线完成实际渲染；延迟管线的插值兼容性已按本地接口检查，未单独完成延迟渲染验收。

## 未决问题

非均匀缩放、已有 UV 贴图和通用外部模型材质的共存方案，以及其他渲染后端的像素误差范围仍需独立验证。
