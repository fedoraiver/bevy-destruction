# ADR 0016：受损结构求解与窄支撑释放

## 状态

- 已采用并实现；独立困难图、完整测试和实际图形倾倒验收完成。
- 日期：2026-11-17。
- 扩展 [ADR 0010](0010-elastic-interface-stress-and-overload-fracture.md) 的求解路径，不更改物理 Anchor 的含义。

## 背景与复现

用户在默认矩形楼中用左键逐块挖除底层，观察到上部悬挂，并提供 216 块分量求解 3000 次后相对残差约 `1.52e-6` 的警告。默认目标为 `1e-8`，因此该结果被正确标为无效；原系统随后停止这个分量的应力断裂，但由于仍有路径连到地基，整个分量继续作为静态刚体，形成停滞。无效结果在 HUD 显示为零承载率也容易误导。

可重复的真实资产对照：

- A194：删除 `rectangle` 所有 `part_id` 含 `-l00` 的首层块，只保留 `wall-inner-0-l00-p0000-z00` 两块门框。194 块仍通过 44 个地基锚点连通。
- 其中面积约 `0.0064 m²` 的桥连接承担约 `91,328.84 kg` 上部质量；仅平均压应力已约 `140 MPa`，超过 `30 MPa` 抗压强度的 `4.666` 倍，还承受偏心弯矩。按原参数就应断裂，无需凭视觉或重心位置强制释放。
- 原运行时 240 固定步后仍零位移、零倾斜、零断键，失败 4 次，残差约 `3.20e-7`。
- 独立数值复现：保留 255 块，在 `Y=1 m` 两侧只保留 `bond_da333b7d157787cb4b2d6145` 这一真实接口，旧求解残差约 `1.174e-6`。
- B217：删除首层 `position.x < 4.04` 的块，恰好保留截图同样的 217/255 块；此特定删块组合可收敛，不能仅凭存活数量宣称精确复现用户的全部操作序列。

## 决策与实现边界

- 保留默认 `1e-8` 精度、材料参数、损伤阈值及实际支撑连接；不得把不收敛解释为零应力，也不通过移除锚点、降低全部强度或强制施加倾倒力矩掩盖问题。
- 完整的连通锚定结构允许传递弯矩，因此不引入“重心越过支撑投影就必倒”的规则。用成功的承载计算断开过载连接后，再由真实刚体接触和重力产生下落、旋转。
- 普通图保留原分块 Jacobi PCG；不再在替换残差后继续沿用旧共轭方向。超过 512 次普通迭代，或装配矩阵的候选解未通过原始单元平衡残差时，使用确定性最小度排序的稀疏 6×6 Cholesky 因子作迭代修正。所有普通和修正步骤共用原 3000 次预算。
- 困难路径用高/低两项保存位移修正，用补偿乘加恢复原始界面变形、内力及残差。这样在很大的整体摇摆位移上，仍可保留决定连接内力的细小相对变形。应力恢复和最终残差使用同一变形计算，不能只让诊断数字合格而丢掉内力中的修正量。
- 最终承载结果必须满足原始单元能量导出的自由节点力/力矩残差 `1e-8`；转动分量仍采用原特征长度换算。无效输入、非正定或预算用尽且残差不合格仍明确失败，不添加正则刚度。
- HUD 对全部分量无效的情况显示 `unavailable (retrying)`，不再显示具有安全含义的 `0.00 capacity`。部分有效时继续显示有效部分估计和未解分量数量。
- 新增 `--collapse-smoke-test DIR`，以真实网格/截面、偏侧残余门框 `wall-inner-0-l00-p0006-z00` 和原参数验证大块上部释放、下移、倾斜。该场景同样移除其余 61 个首层块，但与 A194 保留的 p0000 门框位置不同；p0006 的下半块保持静态，上部通过偏侧真实接触产生旋转。记录质量、有限状态、具体支撑碰撞体上的接触冲量、应力诊断及阶段截图，不注入初速度或人工力矩。

## 备选方案与取舍

- 只增加迭代次数不能解决严重条件数和浮点消减误差；放宽容差会改变错误处理边界。
- 支撑投影判断适用于不同的接触/铰支假设，不能替代本项目固定支撑、传递弯矩的接口强度计算。
- 失败时随机切键或强制变成动态会使求解错误直接产生破坏；不采用。
- 高精度困难路径会增加少数步骤的计算和内存开销，应保留正常图的快捷路径并记录实际成本。

## 验证要求与进度

- 独立当前源码验证 70 个不同高度/保留接口的真实矩形窄支撑图，未收敛数由旧实现 16 个降为 0；另有 32 个空间删块图保持通过。这些是数值拓扑验证，不替代可见行为验收。
- A194 集成测试修复后失败次数为 0，4 条强度断键后上部释放并实际下移。整个窄门框同时脱离时，上部可先近乎垂直自由落体；该案例不应被要求凭空产生角速度。倾倒另用偏侧残余支撑/实际接触验证。
- 真实首层 17 种残余构件的诊断扫描中，p0006 门框场景保留下半静态构件并产生偏心接触；200 固定步内上部 148 块达到约 `0.853 rad` 倾斜、`0.792 m` 下移，强度断键 2 条、失败 0。永久回归进一步要求具体残余碰撞体上的非零求解冲量，避免仅在地面翻滚也算支撑倾倒。
- 独立恢复的自由节点与全局力/力矩平衡、150 块上部质量的桥连接解析合力/力矩，以及小图稠密参考均需通过；解析零分量采用相对于完整合力/力矩的向量误差，避免把极小绝对误差误判为全场失衡。
- 完整 Rust 测试 82 项通过，0 失败、0 忽略；最后一次等价迭代器整理后，应力相关 22 项复验通过。`cargo clippy --all-targets -- -D warnings`、`cargo fmt --check` 和正常引擎构建通过。
- 真实引擎执行 `--scene rectangle --collapse-smoke-test output/acceptance/support-tipping`，退出码 0、报告 `errors=[]`，四张阶段图与删块回放完整。上部 148 块在第 21 帧释放，第 154 帧观察到倾斜；最大倾斜约 `1.721 rad`（98.6°）、最大下移约 `1.750 m`，与指定残墙碰撞体有非零接触冲量。强度断键 2 条、求解失败 0、无效报告峰值 0，质量误差最大约 `0.019 kg / 115,429 kg`，所有状态有限。倾倒与最终翻侧画面已实际检查。
- 安静单进程复测完整资产：板楼约 `36.1 ms / 449` 次、L 形高楼 `24.6 ms / 386` 次、桥梁 `2.17 ms / 188` 次、矩形 `10.1 ms / 222` 次，均通过默认 `1e-8`。正常迭代数未改变，新增补偿恢复和物理残差校验有额外成本；此单次 CPU 求解测量不是 FPS。

## 未决问题

当前小变形模型不包含屈曲、大变形、塑性铰、配筋细节或完整动态弹性波。成功收敛只说明本模型中的平衡解有效，不代表工程安全证明。
