# ADR 0010：结构求解与碰撞性能

## 状态与日期

2026-11-17 采用并实现。优化适用于默认开发构建和正常运行时。这里的旧测量使用正式不规则分块发布前的资产。

## 背景

高楼在受损后要重算六自由度结构，落地时大量碰撞和反复准备同一事件的载荷也会拉长固定步。优化以相同构件、材料、精度及断裂条件下的结果对照为前提。

## 决策与实现

- **求解装配。** 按稳定的节点和连接顺序累积稀疏块，一次转换成连续的块 CSR。PCG 复用工作缓冲，按行遍历，减少迭代中的分配。补偿应变计算只跳过恰为零的系数，其余 f64 项保留计算顺序和误差修正。位移低位、真实单元残差和应力恢复沿用 [ADR 0002](0002-elastic-structure-and-overload.md) 的精度要求。
- **锚定分量缓存。** 应力状态留在原 ECS 实体上。实例、外加载荷和求解设置的变更版本以及建筑局部重力用于快速识别相同输入，健康固定步复用键和结果。按分量缓存有效解，锚定分量成员或内部连接变化时重算，独立动态残骸变化时复用未受影响的锚定分量。无效结果进入重试。过载和已有断键仍按固定步处理，单独调整即时断裂阈值时使用新阈值并复用有效内力。
- **动态撞击。** 每个撞击事件只准备一次惯性平衡后的 `InertialLoadCase`，断键后仍按当前有效连接求解。v2 面片直接提供截面顶点。每固定步最多处理一次重型动态求解，首次绑定和分离卸载见 [ADR 0003](0003-collision-driven-fracture.md)。单次求解耗时随图规模变化。
- **碰撞与构建。** 簇重建复用成员及锚定状态未变的刚体，只为新簇重新聚合质量与惯性。开发配置只对本项目、Avian 和 Parry 启用 `opt-level=2`，保留调试信息和开发断言。烟尘的 GPU 数据共享见 [ADR 0008](0008-destruction-effects-and-rims.md)。

## 备选方案与取舍

全依赖优化会增加首次编译成本。同步求解保留确定的固定步提交顺序，异步方案还需处理输入失效、取消和迟到的断裂反馈。分量缓存以额外的键和结果空间换取重算节省。列存储、独立行累加和六行展开在冻结输入下保持了输出，矩阵乘法收益未能稳定复现。

## 验证要求与已完成验证

- 缓存回归覆盖健康固定步复用、载荷与重力变化、容差与支撑变化、移除独立残骸，以及只调整即时断裂门槛。
- `d946c85` 阶段旧板楼的初始自重求解约 `357 → 30 ms`，相同 300 固定步的无图形落地对照约 `10.04 → 2.30 s`。
- `83834c8` 的冻结输入对照保持求解输出逐字节一致。合入烟尘缓冲的 `205c713` 阶段，旧 L 形高楼的隔离程序四次交替运行保持相同破坏结果，平均墙钟帧耗时约 `74.24 → 53.53 ms`。这些是对应旧资产与测量条件的历史数据。

## 未决问题

正式 v2 资产的多面片装配、复合凸接触和渲染开销需要独立测量。大型受损图、密集接触和边带更新仍可能产生长帧。
