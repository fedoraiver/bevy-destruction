# ADR 0022：Rust 模块目录与集中测试布局

## 状态

- 日期：2026-11-17。
- 用户明确要求，已采用并完成目录迁移；机械迁移后的编译与 100 项回归已通过。
- 本记录同时记录用户在同轮要求的旧版资产兼容移除；机械移动和格式行为变更需按各自范围验证并分开提交。

## 背景

此前运行时模块平铺在 `src`，测试既有文件末尾的内联模块，也有 `*_tests.rs` 和单独的坍塌测试文件。继续增加几何、物理与调试功能时，同一个模块的实现和测试位置不统一。

## 决策

- `src/main.rs` 保留为二进制入口。其余模块统一为 `src/<module>/mod.rs`，模块名和 `crate::<module>` 导入路径保持不变。
- 每个模块的单元测试统一位于 `src/<module>/tests.rs`，实现文件仅保留 `#[cfg(test)] mod tests;` 声明。
- 同一模块的多个测试主题可在该 `tests.rs` 中使用内联子模块隔离辅助函数和导入，不再分散为其他测试文件。
- 仅供测试使用的辅助函数也移至对应 `tests.rs`；不为目录调整扩大运行时接口的可见性。
- `include_str!` 等相对路径随源文件深度调整。资产根目录、命令行、物理参数和运行时行为不由此次移动改变。

## 备选方案与取舍

- 继续平铺、按文件名区分测试：移动成本最低，但不符合用户要求。
- 统一到顶层 `tests/`：适合只依赖公开 API 的集成测试；现有求解器和生命周期回归需要访问模块私有实现，因此本轮采用模块内 `tests.rs`。
- 为每个测试主题再建文件：会继续分散同一模块测试，本轮使用一个文件内的测试分组。

## 实现与验证

- 已迁移 26 个实现模块，并集中 18 个模块的测试。
- 已检查 `src` 顶层仅保留 `main.rs`，测试函数仅出现在各模块的 `tests.rs`。
- `cargo +1.99.1 test -- --nocapture`：100 项通过，0 失败，测试部分耗时 4.45 s；迁移前后测试数量一致。
- `cargo +1.99.1 fmt --check` 通过。
- 严格 Clippy 已运行；报告受力显示中的可合并条件和折面测试中的索引循环两项既有告警，未发现目录或路径迁移错误。这两项由对应功能负责人处理，不能将本记录视为最终全工作区静态检查已通过。

## 同轮资产格式收敛

- 用户明确不需要旧版资产兼容，读取器仅接受 `schema_version=2`。
- 本节取代 [ADR 0020](0020-production-irregular-fracture.md) 中继续读取 v1 的接入决定；既有研究和测量作为历史保留。
- 每条连接必须在反序列化时提供 `patches`，且验证时要求至少一个真实面片；不再以父连接的单平面字段补出缺失面片。
- 接触显示只读取规范面片，并检查真实显示网格的覆盖；移除从旧显示网格重新猜测平面接触的回退路径。
- 显示材质必须提供有效的 `extras.bd_surface_role`，不再通过旧材质名称推测断面，也不将缺少角色标记默认为外表面。
- 旧资产需重新烘焙。保留的历史数值回归须转为具有真实面片的 v2 测试数据，不保留旧格式读取路径。平面解析测试仍可用单个真实平面片表达，这属于当前格式的合法特例。
- 上述格式行为变更的聚焦测试及新正式资产验证单独记录，不能以此前机械迁移的 100 项通过结果替代。
- 格式收敛后的 9 项资产解析/验证测试和 11 项接触显示测试通过，分别覆盖必填面片、拒绝旧版本、明确材质角色、折面覆盖、真实边缘、薄墙、间隙与小凹口；两项正式资产集测试保留，待 v2 重烘焙后再运行。
- 双柱梁验收数据改为直接构造当前格式的 SI 材料、刚体与两个真实平面截面，不再克隆正式矩形楼。其他独立刚体、图和反馈测试以此构造自身数据，避免正式分块变化改变合成测试的初值。
- 原窄支撑失败图已在 `src/stress/fixtures` 中重建为当前格式：保留 255 个块及 845 条连接的身份、拓扑和质量；从实际凸代理接触重建每个平面多边形，再按序列化顶点重算截面物理量。最大面积相对变化约 `5.86e-5`、中心变化 `1.04e-6 m`；两个关键失败截面的相对面积变化约 `1e-7`。旧根目录 v1 数据已在新图通过验证后移除。
- 当前格式的梁、失败图、求解器及结构运行时 24 项聚焦回归通过，0 失败，测试部分耗时 0.72 s；其中包含新图完整资产验证、原受损支撑、力矩平衡、真实下落及残桩接触。
- 合成夹具迁移后的刚体 5 项、连接图/质量 5 项及破坏反馈 2 项回归通过；单位立方体夹具在每次构造时执行当前格式校验，质量与对应材料密度一致，既有速度、质量与动量检查保留。

## 验收路径一致性修正

新分块下偏侧支撑由多个碎块组成。无图形回归已检查全部仍为静态的支撑路径成员，但图形脚本此前只取第一块，可能漏掉上方支撑的实际冲量。图形脚本现采用相同的完整路径判定，并在报告中记录真正发生接触的碎块身份；仍须同时满足大块刚体、静态支撑刚体、准确碰撞体和正接触冲量。

独立回归覆盖“下方 0004 没有冲量、上方 0005 有真实冲量”，并拒绝零冲量、错误动态刚体和错误静态刚体，1 项通过。实际图形复验单独记录，不以这个无图形检查替代。

## 未决问题

后续新模块和新测试须沿用该布局。现有受力显示、新分块及资产格式变更仍按各自决策记录独立验证，不能以目录迁移检查替代其功能验收。
