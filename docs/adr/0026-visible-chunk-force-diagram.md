# ADR 0026：仅显示可见碎块的受力图

## 状态与日期

- 日期：2026-11-18。
- 已采用并实现；替代 [ADR 0021](0021-structural-force-visualization.md) 中跨全部碎块透视绘图的显示范围，内力、冲量来源及有效期不变。
- 数值与图形验证结果在本记录的验证部分分别列出。

## 背景

原 `9` 视图把全部存活碎块的质心、连接与箭头透视绘出，前后墙及室内构件重叠。用户要求说明线框含义，并仅保留当前能看到的 Chunk 的受力图。仅检查视锥或 Bevy 的继承可见性无法排除被建筑遮住的后方碎块；只检测质心又会遗漏从洞口、破口或边缘露出的碎块。

## 决策与实现

### 可见碎块的选择

- 独立 `force_visibility` 模块读取实际源三角形及刚体当前渲染变换。源三角形位于建筑静止坐标，包含真实洞口；不使用填满洞口的复合凸代理来遮挡建筑。
- 将源三角形裁剪到活动透视相机的近、远及侧边界，再按投影面积选取面内采样点，包含中心与靠近边角的点。每块至多 64 个样本，任意样本的目标表面先于其他实体命中，即选中该块。
- 射线从相机近面出发，先求目标自身的第一个真实表面，再判断其他块、可见地面和刚性撞击物是否更近。采用非实心表面求交，支持相机在闭合几何内部。非均匀变换后的命中距离换算回世界距离。
- 建筑查询使用源三角形 BVH；地面、球和方块使用对应已缩放 Collider 的查询几何。查询几何不加入物理世界，不增加接触或改变质量。
- 相机、投影、碎块渲染位姿、存活集合、继承可见性或其他遮挡物形状改变时，立即丢弃旧可见集合，避免沿用旧视角的穿墙结果。资产 Modified/Removed 事件清理源几何缓存；同一资产和块 ID 的三角形视为不可变，编辑须触发资产失效。

### 图形保留规则

- 蓝色质心十字仅为选中块绘制。
- 两端都不可见的连接不绘制白线、外框、彩色内框或 F 箭头。
- 至少一端可见时保留连接中心标记，只绘制可见端的质心至连接中心线及该端 F 箭头；两端可见才形成完整的一对箭头。显示省略不改变作用力与反作用力的实际计算。
- 紫色历史 J 箭头要求所属 Chunk 可见，仍停留在真实事件世界位置，并按原 1 秒有效期淡出。
- 选中块内部继续使用诊断透视绘图，便于看清埋在自身表面内的连接中心与质心。这是按块筛选，不对每段线单独进行像素深度裁剪；一个局部可见块的内部标记仍可能透过其自身或局部前景显示。
- HUD 的 F/M/U 与箭长参考改为可见连接的当前有效样本，额外显示可见块数、实际形状射线查询数及预算未完成数。没有有效可见结果仍为 `unavailable`。

### 图例与尺度

| 图形 | 含义 |
| --- | --- |
| 蓝色小十字 | Chunk 真实质心 |
| 细白线 | 可见端质心至有效连接中心的关系 |
| 白色八面体外框 | 有效静态连接的界面位置，不是额外强度或形变 |
| 青色外框 | 撞击等效内力工况，即冲量经 10 ms 标定及惯性平衡后的结果，最多保留 0.7 秒 |
| 彩色内框、F 箭头 | 连接承载率 U；绿 `<0.5`、黄 `0.5≤U<1`、红 `U≥1`，箭头方向来自真实合力 |
| 紫色 J 箭头 | 实际法向接触冲量，单位 N·s，最多保留 1 秒 |

F 单位为 N，M 单位为 N·m，U 为求解器恢复的应力与强度判据。内框尺寸随 `sqrt(clamp(U,0,1))` 增大，在 U=1 后封顶；超载数字继续增长。F、J 各按当前可见有效最大幅值独立线性缩放，最长 0.75 m；跨视角比较须结合 HUD 数值。M 以数值显示，不用另一种箭头表示。该视图不显示弹性或弯曲形变。

### 成本与边界

- 每帧至多 8192 次实际形状射线求交，计入目标自身；AABB 预筛不计为形状射线。
- 几何 BVH 按资产和块缓存，首次开启的懒构建可能产生一次 CPU 峰值。视图静止且场景不变时复用分类结果，不继续求交；预算未完成的块暂时隐藏，相同场景后续帧继续分类，直到完成。8192 上限仅限制形状求交，不限制三角形裁剪、排序等准备工作。
- 视图关闭后不进行可见性采样、几何构建或射线检测，保留已有不可变几何缓存供下次启用。原 3000 条图连接、400 个按承载率优先的内力标记上限继续适用。
- 有限采样不是逐像素 ID 缓冲：极窄暴露边缘可能漏选。仅支持项目实际使用的单个活动透视 DemoCamera 和不透明建筑、地面及撞击物；透明物体、多相机分层或任意非 Collider 遮挡网格需另行扩展。预算与缓存不构成帧率保证。

## 备选方案与取舍

- 仅视锥筛选成本低，但后方建筑仍穿透显示，不满足遮挡要求。
- 仅质心射线容易遗漏质心被挡住、边缘仍可见的碎块；采用真实表面多点采样。
- 直接启用所有 Gizmo 深度测试会隐藏埋在可见块内部的节点和箭头，不能表达按 Chunk 选择后的内部受力关系。
- GPU Chunk-ID 读回可提供逐像素结果，但需要独立渲染通道、读回延迟与相机同步。本次使用有界 CPU 查询；GPU ID 颜色用于独立验收，不作为运行时依赖。

## 验证要求与已完成验证

- 已通过 23 项受力相关 Rust 测试，包含前后遮挡、真实窗洞、仅边缘可见、视锥裁剪后可见、非均匀缩放、相机内部、渲染位姿变化、遮挡物修订、缓存失效、关闭路径及预算续算。
- 图形路径在原真实自重、断键、实际刚球冲量及关闭检查后，增加源 ID 基准、筛选后的力图、关闭重复基准三阶段。固定夹具使用与查询完全相同的实际渲染三角形，要求后方块为零源 ID 像素、窗洞及局部暴露块有真实像素，实际提交集合、单端箭头数与图像变化同时符合预期。夹具中的确定性 N 只验证显示筛选，不代替前五阶段的真实物理结果。
- 最终完整 Rust 回归：138 通过、1 失败、0 忽略，测试部分 6.04 秒。唯一失败仍为 ADR 0024 已记录的 `projectiles::tests::dropped_upper_tower_fractures_on_ground_contact`：18 次求解/18 个断键，分量大小 `[1,1,116]`，落地破坏程度偏轻；本次未改物理或放宽断言。
- 正常程序构建、`cargo +1.99.1 clippy --all-targets -- -D warnings`、`cargo +1.99.1 fmt --check` 及 `git diff --check` 均通过。
- 实际执行 `--scene rectangle --force-smoke-test output/acceptance/visible-force-graph`，退出码 0、`errors=[]`，八张图全部生成。使用正式矩形 `28d80db4a70baff023c26c907b2aab492e93c830225a101b2ec60bb7e5b68fee`，163 块/2143 代理；有效自重可见连接 263，实际 366 支箭头（130 对），63 个可见块，静止截图帧射线数为 0。最大可见 F 约 84.742 kN，实际接触 J 约 722.073 kN·s、79 个紫色像素，断键隐藏和关闭清空均通过。

## 未决问题

采样无法保证极细露出区域的逐像素完整性。大型运动场景中相机或任意遮挡物每帧变化会持续失效缓存，可进一步采用空间增量失效或 GPU ID 通道；须先用相同可见集合和图形门槛比较，不能以降低遮挡正确性宣称优化。原大块落地破坏偏轻问题仍按 ADR 0024 独立跟踪。
