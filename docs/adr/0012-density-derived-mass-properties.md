# ADR 0012：Avian 按碰撞体与密度计算质量属性

## 状态

2026-11-19 采用并实现。替代 [ADR 0001](0001-rigid-cluster-runtime.md) 原先的显式刚体质量与簇聚合方案，以及 [ADR 0005](0005-v2-asset-contract.md) 原先的导入端质量属性覆盖。历史方案见提交 `abc7e35`。

## 背景

建筑碰撞体由实际参与接触的凸代理组成。原运行时以 Blender 烘焙的逻辑块积分设置刚体，并为簇另行组装完整惯性。自重和撞击断裂也需要质量分布，拆簇还需要在物理求解前知道新旧质心，以继承刚体速度场。

## 决策

- 给每个 Chunk 的实际复合 Collider 设置材料 `ColliderDensity`，并用 Avian 的同一计算入口取得碎块级质量、质心和完整惯性。不可解析的质量属性通过建筑导入错误路径报告碎块 ID。混合材料簇由 Avian 汇总各成员，换属完成后立即更新新刚体的 `Computed*` 属性，再用计算出的世界质心初始化分离速度。
- 自重作用在 Avian 质心，接触冲量矩也以该质心为参考点。动态冲量的惯性平衡用同源碎块属性以 `f64` 组装。锚定自重及动态载荷进入结构求解时，力矩按 $T_{\text{节点}}=T_{\text{质心}}+(c_{\text{质心}}-c_{\text{节点}})\times F$ 转换。结构节点和等效截面长度继续由 v2 清单几何确定。烘焙质量、惯性及体积仍用于资产校验和制作审计，已有资产可直接加载。
- 球和方块各自按 Avian 计算的单位密度质量换算密度，实际刚体目标质量均为 `8000 kg`。

## 备选方案与取舍

逻辑块烘焙值表达源实体的质量分布，要求刚体维护一套显式覆盖与聚合。让 Avian 以接触几何积分，使物理与载荷共享材料密度和代理，运行结果随代理几何精度变化。复合碰撞体按子形状累计质量属性，重叠区域会被重复计入。当前制作端验证代理覆盖及积分误差，较大的代理误差仍会反映到运行时质量。

## 验证要求与结果

- `cargo test --release --locked --offline` 通过 146 项。六个正式场景的凸代理密度积分及自重平衡通过，偏心混材质簇的完整惯性、首次拆分的速度和动量、删块减重、接触换属，以及两种撞击物的质量、惯性和真实碰撞断键均通过。
- 矩形楼的物理、自重与撞击、偏支撑倒塌烟测均通过。板式高楼的落地烟测也通过，22 次动态求解均有效，力和力矩的最大相对平衡误差分别为 `2.1e-15`、`9.3e-16`，满足 `1e-6` 门槛。
- 质量属性切换时，完整测试的唯一失败是板式高楼严格落地回归。前后均为 18 次动态求解、18 条断键，最终分簇为 `[1, 1, 116]`，见 [ADR 0003](0003-collision-driven-fracture.md)。

## 未决问题

大尺寸资产和薄代理的质量误差需随资产规模继续评估。板式高楼严格落地的后续验证见 [ADR 0003](0003-collision-driven-fracture.md#验证要求与结果)。
