# ADR 0012：排除低于几何精度的线状承载接触

## 状态

- 已采用、已实现，验证范围如下。
- 日期：2026-11-17。

## 背景

应力求解开发发现少量原始资产 Bond 具有近似秩一的接触二阶矩。例如矩形中的 `bond_55c2365559ee8a24eb4a8101` 面积约 `7.25e-9 m²`，实际是共边附近的数值细条，不能提供可分辨的二维承载截面。

原制作工具仅要求面积大于位置容差平方，不能排除长度较大、宽度却小于位置精度的细条。它们经 float32 存储后可能出现零或负的切平面二阶矩行列式。通过增加虚构刚度、隐藏锚点或在求解器里静默忽略错误，会掩盖资产制作问题。

## 决策

- 保留 `2e-5 m` 接触位置容差；凸接触多边形的最小平面宽度必须严格大于该容差，面积还须大于容差平方。
- 最小宽度取多边形各边法向上的投影跨度之最小值；共边、共点及低于精度的细条不导出 Bond。
- 宽度足够的真实窄面仍保留，不采用按整体建筑尺寸或材料强度删除连接的经验阈值。
- 此规则在制作端统一作用于连接和接触表面分类。运行时继续拒绝真正无效的截面，不提供任意正则刚度。
- 重新烘焙旧资产并保持种子、Chunk、质量、惯性与 Anchor 身份；原有内容哈希 GLB 保留。新清单和对应几何一起发布。

## 已实现与已完成验证

- `bonds.py` 对共面凸多边形重叠增加最小宽度检查。
- 制作回归确认 `1e-5 m` 宽细条不产生 Bond，而 `1e-4 m` 宽的可分辨接触仍导出正确面积。
- 矩形 Bond 数 `849→845`，L 形 `1686→1654`，庭院 `1183→1176`；Chunk、Anchor 数量不变，全部 Chunk 仍与固定地基连通。
- 三个最终清单经 float32 量化和独立切平面投影检查，二阶矩均非退化。仅 L 形显示 GLB 内容哈希改变，旧 GLB 未删除。
- Blender 几何、制作导出、表面和现有资产表面回归全部通过；本次完整制作验证共 28 项，通过的具体目录测试另见 ADR 0011。

## 备选方案与取舍

- 仅按面积过滤不能可靠识别长细条，故增加宽度条件。
- 提高所有连接的面积阈值会丢失真实窄截面，当前规则直接使用已有几何精度。
- 求解端补刚度会让不可解析的线接触承担弯矩，本轮不采用。

## 未决问题

远大或远小于米制样例的资产可能需要重新制定几何精度及导出数值约定；本规则不是跨任意尺度的精度保证。
