# 架构决策记录

本目录保存 Bevy 建筑实时物理破坏插件的设计决策、重要设定及验证边界。

## 状态说明

- **提议（待原型验证）**：当前设计方向，尚未视为最终选型或完成实现。
- **部分已采用**：仅记录中明确指出的条目已作出决定，其余条目仍为提议；实现和验证进度需分别说明。
- **已采用**：已作出的设计决策；实现和验证进度仍需单独说明。
- **已被取代**：保留历史，并链接替代它的新记录。

截至 2026-11-16，用户已确定使用 Bevy 0.20.x + Avian 0.8.x，并选择 Blender 作为资产制作工具；具体补丁版本与 features 待实现阶段锁定，项目仍为尚未添加相关依赖的 Rust 初始工程。各记录分别标注已采用条目和待验证提议。工具选定不代表集成和自动生成流程已全部实现；60 Hz 固定步等集成设定仍为提议。Blender 制作流程的调研及局部验证范围见 ADR 0005。
