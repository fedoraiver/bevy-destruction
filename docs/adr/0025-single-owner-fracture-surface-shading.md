# ADR 0025：断面与外表面的单次片元着色

## 状态

- 日期：2026-11-18（复现与实现始于 11 月 17 日）。
- 已采用并实现；原失败已在真实 GPU 复现，修复后的完整图形对照通过。
- 取代 ADR 0023 的独立共面显示层；源资产、规范接触几何、碰撞、质量、拾取和结构计算保持原职责，无需重新导出资产。

## 背景

用户报告断裂面在 grid 与棕色粗糙材质之间闪烁。ADR 0023 保留源面，又在其附近绘制独立的规范接触面，使用固定 `depth_bias=2`。规范面与真实 float32 GLB 的局部允许差为 40 µm，另有局部坐标变换、三角形插值及透视深度量化差；固定深度单位偏置不能表达固定物理距离。

已有静态截图确认断面能够出现，不能证明移动视角下两种材质不会争用深度。需以真实 GPU 图像将叠画结果与仅有正确断面材质的参考逐区域比较，并保留外墙和前方遮挡物检查。

## 决策

- 保留实际源三角形，在其同一次 fragment 中按规范接触多边形选择 grid 或粗糙断面，取消生产场景的独立接触显示层。
- 由制作端既有表面角色处理完全断面；只为其余源三角形建立实际有限重叠的候选接触列表。无候选直接显示 grid，不遍历整栋楼的连接。
- 使用随物体运动的静止建筑坐标和 origin-relative 凸半空间判定，保留洞口及部分覆盖区域。不得以整面改色、填凹凸包或位置偏移替代实际接触区域。
- 候选表及多边形使用按资产缓存的共享只读 GPU 缓冲；候选集合与多边形去重。仅在需要时展开显示网格的索引顶点，保留真实顶点位置、法线、三角形及拾取/碰撞数据。
- 第二 UV 通道的空闲分量保存每三角形相同的候选索引；GPU 四舍五入读取，限制可精确表示的索引范围。其余静止材质坐标保持原义。
- 所有屏幕导数在按片元的材质分支之前求值；保留正常深度测试、深度写入、阴影和深度预通道。没有额外的断面深度偏置。
- 外表面材质也预置其物理类别的断面颜色、微法线幅值、粗糙度和金属度，命中区域时完整应用；钢、木、砖不会被统一误画为混凝土。保留导入材质原有的双面和剔除状态。
- UV 索引限制小于 `2^20`，保持 Float32x2，不压缩第二 UV 通道；GPU 对插值索引四舍五入。多边形边以相对原点表达，边判定余量为 `0.5 µm`；候选平面仍使用原 `40 µm` 有限重叠域门槛。

## 备选方案与取舍

- 增大固定深度偏置：不能同时代表不同视距、掠视角和局部几何误差，且可能穿过前方表面，不采用为最终修复。
- 沿法线移动显示顶点：可缓解竞争，但改变了显示几何并在薄壁和接缝处产生浮层，不采用。
- 重新对源网格离线切割：ADR 0023 已记录复杂微小交点的稳定性问题，不恢复未通过的试验路径。
- 单次片元着色增加局部候选判定及缓冲读取，换取材质拥有者唯一、取消显示层绘制和管理。需记录真实资产的缓存规模和验收，不推断未经测量的帧率。

## 验证要求

- 修复前旧显示层必须在透视近距离、符合既有误差门槛的微小间隙条件下呈现 grid 泄漏；正确断面参考必须确实可见。
- 修复后在近/远/掠视、刚体平移旋转、深度预通道开关下与正确参考一致；接触范围外仍为 grid，前方物体仍正确遮挡。
- 单元检查几何及原有属性保持、候选筛选、洞口/不连通区域、索引和共享缓存；六正式资产继续通过原接触及自重检查。
- 旧高楼落地破坏程度失败另见 ADR 0024；不修改其物理逻辑或验收门槛。

## 实现与已完成验证

- 最小修复前对照使用 3 m 透视、near=0.05/far=500、源面 z=0 与规范接触 z=-10 µm，复用实际 BuildingMaterial 和局部逆变换。`output/acceptance/contact-legacy-red` 真实退出非零：中心 23104 像素中 96.014% 显示错误 grid，平均 RGB 误差 15.632；纯断面参考明确可见，排除了黑图假阳性。
- 同一最小条件修复后 `output/acceptance/contact-mask-first-green` 退出 0，错误像素比例降为 0，平均误差约 0.00382；接触外仍保留 grid。
- 完整 `--contact-smoke-test output/acceptance/contact-mask-matrix` 退出 0、`errors=[]`，40 张有效图像、0 次读回拒绝。覆盖深度预通道开/关 × 3 m 近景、100 m 平移、72° 掠视旋转及背面旋转，共 8 组；每组有 grid、纯粗糙参考、源面 mask、旧显示层负对照和重复 mask 画面。每张包含六位阶段见证，防止异步读回上一阶段。
- 每组两次正例的接触错误像素比例均为 0，最大平均 RGB 误差 0.01527；外部 grid、前方绿色遮挡物及重复捕获的误差均为 0。最小有效 ROI 分别有接触 17180、grid 55940、遮挡 1886 像素。近景、远景、掠视、背面及负对照图均已目视复核。
- 旧负对照在两种预通道状态下均为近景 95.346% 错误、掠视 61.315% 错误，100 m 远景恢复正确棕色；直接复现了视距/角度改变时两种材质切换。普通与预通道行为一致，不是 Equal 比较或遗漏偏置的问题。
- 七项 mask 回归通过，含真实 GLB 舍入面、部分区域、洞/不连通集合、法线/间距负例、原属性及几何保持、去重和六资产实际生成。材质类别、缓存域隔离/失效及四项图形脚本 ROI/阶段见证/双面设置回归通过。
- 既有 `--material-smoke-test output/acceptance/contact-mask-material-motion` 退出 0：平移和旋转错误像素比例均为 0，世界锁定负对照有 3.7338% 变化，证明材质仍随物体运动。真实矩形 `--smoke-test output/acceptance/contact-mask-rectangle --no-vfx` 退出 0，实际破口与近景已检查。
- 最终全套 Rust 为 124 通过、1 个原有高楼落地程度失败、0 忽略；旧失败仍为 18 断键与 `[116,1,1]`，没有改动物理路径或门槛。严格 Clippy、正常构建和格式检查通过。

## 未决问题与来源

来源为用户报告、ADR 0023、固定依赖 Bevy PBR 0.20.1 的 `pbr_material.rs`、`prepass/mod.rs`、`render/mesh.rs` 及共享 `ShaderBuffer` API。普通 opaque 和 depth prepass 均使用 GreaterEqual；没有把 deferred lighting 的 Equal 设置误认为当前主通道行为。
