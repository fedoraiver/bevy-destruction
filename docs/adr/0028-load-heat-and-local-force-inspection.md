# ADR 0028：受力热力与局部详查

## 状态与背景

2026-11-18 已采用，替代 [ADR 0026](0026-visible-chunk-force-diagram.md) 的全场线框。[ADR 0021](0021-structural-force-visualization.md) 仍定义内力和冲量。此前矩形楼仅选 63 个可见碎块仍会画出 366 支箭头，连接、内外框和质心相互叠加。用户选择让总览只突出高负载区域，并按住 `Alt` 详查准星目标。

## 已实现的决策

- `9` 和小键盘 `9` 切换视图，默认关闭。总览每块取有效相邻连接的最高承载率，`U < 0.5` 或无有效结果保留原色，`0.5 ≤ U < 1` 为琥珀色，`U ≥ 1` 为红色。`0` 仍控制原分块边线。
- 源网格的每个实例以 `MeshTag` 表示颜色档位，仅在档位变化时更新。原着色器在网格/断面材质确定后混色，保留亮暗细节、法线及表面属性，由同一次不透明绘制处理遮挡和预通道。关闭视图重置所有着色标签及调试样本。共享资产的实例拥有各自标签。
- `Alt` 按住且窗口聚焦、相机捕获输入时，用准星的一条射线命中最近源三角面。射线从相机近面开始，按当前渲染姿态查询，允许穿过真实洞口，受不透明建筑、地面和刚性撞击物遮挡。不同碎块在同一深度命中时不选定目标。以资产和块缓存源三角形 BVH，资产变更或移除时失效。总览无需原多点可见性检测。
- 单块面板按 U 降序列出最多三条有效连接，同 U 按连接 ID 排序。显示 F、M、U 及静态或撞击工况。第一条有非零 F 时在瞄准表面画一支实际力方向箭头，另一端省略。箭长为 `min(0.35 m, 0.12 × 准星射线距离)`，用于控制画面大小，力值看面板。独立显示该块仍有效的最大真实法向冲量 J。
- 静态数据须匹配当前输入及有效解。断开的连接、分离的成员和失效的老样本不能用于着色和详查。撞击等效内力保持 `J/10 ms` 工况与 0.7 秒时限，真实 J 保持 1 秒时限。松键、失焦及无命中时不保留选择。资产、刚体和求解器按原路径运行。

## 备选方案与取舍

- 限制全场箭头数可以降低密度，但排名和观察角度变化容易使标记跳变，且丢失整片结构的受载分布。分级表面色能同时表示所有露出的热点，具体方向留给单块详查。
- 为每块创建材质或额外的共面蒙层会增加资源、绘制或深度竞争。每实例标签配合现有着色器可以独立更新颜色，并沿用 [ADR 0025](0025-single-owner-fracture-surface-shading.md) 的单次片元着色。

## 验证要求

固定载荷回归覆盖 50%/100% 阈值、F/M/U 排序与方向、数据失效和源几何拾取。实际图形检查覆盖无箭头总览、窗洞、完全遮挡、实例隔离、局部单箭头、关闭恢复和开启深度预通道。继续检查真实自重和真实撞击数据。

## 完成验证

- 正式矩形 `28d80db4…68fee` 的 `--force-smoke-test` 完成 11 张实际渲染截图，退出码 0、`errors=[]`。自重数据保留 524 条有效连接、最大 F 约 `90.316 kN`，真实碰撞读取约 `722.073 kN·s` 的法向冲量。断键失效、关闭清空、样本到期和新样本恢复均通过。
- 开启深度预通道的双实例夹具中，窗洞后两块分别检测到 9,990 / 9,614 个琥珀色像素，露出的断面检测到 6,369 个红色像素。前方遮住的红块、低于阈值的块及共用资产的中性实例均无热力像素变化。`Alt` 通过真实窗洞选中目标，画出 1 支箭头并读回 60 个青色像素。无有效数据时面板提示不可用且没有箭头。松键及关闭后各源区域无超出对照门槛的差异，共核对 138,296 个源表面像素。验收拒绝三次未就绪读回，含一次只有深度轮廓的材质画面。报告位于 `output/acceptance/force-heat-final`。
- 原有四张材质运动对照和八组 40 张断面着色对照通过，报告分别位于 `output/acceptance/force-heat-material` 和 `output/acceptance/force-heat-contact`。
- 正常构建、严格 Clippy、格式及差异检查通过。完整 Rust 回归 146 通过、1 失败、0 忽略。唯一失败为 [ADR 0024](0024-fresh-impact-event-rebinding.md) 已记录的高楼落地破坏偏轻，仍为 18 次求解、18 个断键和 `[1,1,116]` 分量。

## 未决问题与来源

颜色表达相邻连接的最高利用率，块内的连续应力分布与完整全局力流超出此视图。场景外扩展的自定义渲染道具需要自行接入遮挡查询。来源为用户确认的交互方案、项目的现有求解与源三角网格，以及仓库锁定的 Bevy 实例标签接口。
