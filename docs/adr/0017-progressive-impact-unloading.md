# ADR 0017：逐连接撞击断裂与分离卸载

## 状态

- 已采用并实现；真实楼体、撞击强弱对照、完整测试及下述图形验收完成。
- 日期：2026-11-17。
- 修正 [ADR 0014](0014-inertial-cluster-impact-fracture.md) 的动态候选队列和拆分后事件重分组策略；保留其惯性平衡和数值规范模型。

## 背景

ADR 0014 的首轮实现将完整动态簇一次求解中所有超过强度的连接都保存到全局待断队列。随后即使结构已经分开，仍继续执行旧应力场的断裂名单；未处理的原始接触冲量也会重新分配给更小的分量。首个裂缝本应改变传力路径并卸载，原处理却会继续清空连接。

旧回归在 300 固定步内断开上半楼体 716 条连接，236 块全部成为单块；此前图形验收也将 227 块全部拆开。这些历史结果只能证明会破坏，不能作为合理破碎程度的验收标准。用户明确要求既不能完全刚性，也不能默认全碎。

这里的重分组影响虚拟结构分析载荷；旧代码也没有向 Avian 重复施加物理冲量。问题是原载荷和待断名单未随传力路径变化卸载，而非后端动量被重复施加。

## 决策

- 多块动态簇的每次有效求解，只选择当前最高承载率、稳定 ID 次序的一个超载连接。
- 连接提交并重建刚体后，后续候选必须使用当前连接图重新求解；不把动态全场利用率永久加入旧的局部冲量待断队列。
- 如果原簇的成员已经分离，结束这个已经施加物理冲量的完整簇事件，不向子簇重新注入父簇大小的原始冲量。不因此删除任何未断连接。
- 如果成员被点击移除，则明确作废对应事件；建筑消失或事件没有内部连接时退出。稳定而未超过强度的当前解同样结束事件。
- 子簇后续破坏需由新的真实碰撞事件触发。整体首次分离卸载是可解释的近似，未模拟裂缝两侧继续传播的完整瞬态应力波。
- 保留原材料、`10 ms` 撞击载荷标定、`2 m/s` 资格门槛、每步一个重型求解和最多 8 个全局撞击断键预算；动态路径每次只提交一个经当前图验证的连接，局部静态/单块路径保留原预算。
- 诊断区分动态断键、因分离释放的事件、因成员消失作废的事件、待求解数量及峰值承载率。没有按固定块数、比例或随机数强制保留残骸。

## 备选方案与取舍

- 全局提高材料强度、拉长标定时间会同时改变其他承载或撞击行为，不能修复过期应力场仍在断键的问题；本轮先不采用。
- 限制总断键数或强制保留某百分比仅掩盖症状，无法保证不同撞击强度有相应变化。
- 拆分后把完整冲量转给小块会改变原事件的惯性尺度；将原事件卸载后，由真实新碰撞继续驱动，代价是没有模拟该脉冲分离后的完整波传播。
- 每断一处重算比一次保存全部候选需要更多求解；按固定步预算处理，正确性和性能需同时验收。排队时间不是材料接触时长。

## 验证要求与进度

- 新的真实 236 块上半楼体回归在旧实现上因“全部单块”明确失败；首轮修正后通过，继续要求远离接触面的内部楼层断裂、明显拆分、质量保留、有限状态、自由落体不损坏和载荷平衡。
- 原 300 步场景修正后断开 48 条连接，形成 `[220,13,2,1]` 的多级残骸；13 块部分约 `45.7 t`，由接地层 5 块楼板和 8 块墙组成。断裂跨 `Y=16.1–23.1 m` 的楼板/墙体连接，全部屋顶仍属于主簇，排除了仅掉屋顶的假通过。主簇保留约 93.2% 质量和原层高跨度，不能据此声称已经模拟楼层压实。
- 新增同一楼体从 `0.5 m` 与 `16 m` 落地的对照，仅改变实际初始离地高度，不改强度、几何或注入速度；需验证实际接触速度差异、较强撞击导致更多断裂，并保留成组结构。
- 420 步高度对照实际速度约 `3.107 / 18.312 m/s`，断键 `11 / 57`，最大簇 `235 / 219`，两者均保留成组结构。7 项冲击相关测试通过；完整新核心集成和实际画面结果待补充。
- 新增队列事件遇原簇拆分后不再求解、不给子簇重新生成候选的回归。
- 图形验收保留内部断裂检查，并增加存活多块簇、保留内部连接和最终簇大小分布；不得把全部连接断开再记为通过。报告的断键统计、内部连接及簇分布统一取第 500 帧快照，之后等待截图写入，避免混入 500–530 帧的后续碰撞计数。
- 完整测试 82 项通过、0 失败、0 忽略；Clippy 严格检查和格式检查通过。原球体/方块反作用、低速接触、自由落体、质量、有限状态、规范点反力回归保留。
- 实际执行 `--scene highrise_slab --landing-smoke-test output/acceptance/selective-landing-highrise_slab`，退出码 0、`errors=[]`，四张阶段图完整，最终局部破损并倾斜的画面已检查。按可见包围盒中点保留的 227 块在落地后形成 `[207,16,1,1,1,1]` 六组；原 669 条内部连接断开 45、保留 624，其中远离接触面的内部断键 33 条，求解失败和待处理事件均为 0，规范反力比约 `1.32e-10`。这与无图形夹具固定 16 m 切面保留 236 块的选取不同，分别记录。
- 最终程序复验 `--scene highrise_l --landing-smoke-test output/acceptance/selective-landing-highrise_l-final --profile`，退出码 0、`errors=[]`。第 500 帧快照中 216 块形成 `[208,4,1,1,1,1]`，629 条连接断开 30、保留 599，内部高层断键 25 条，求解失败/排队为 0；连接总数与同帧断键计数完全对应。450 个实际帧间隔样本平均约 `67.4 ms`、最大 `172.5 ms`；未隔离同机负载，不用它计算算法加速比或承诺稳定 60fps。

## 未决问题

冲击历时、应变率、裂纹耗能和分离后的弹性波仍是模型近似；参数未做工程级混凝土标定。极强撞击可以导致更严重的破坏，本决策不设“永远不能全部破碎”的物理硬上限。
