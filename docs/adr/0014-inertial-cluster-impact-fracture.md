# ADR 0014：动态簇撞击的惯性平衡与内部断裂传播

## 状态

- 已采用并实现；无图形回归和板楼实际图形落地验收已完成。
- 日期：2026-11-17。
- 扩展 [ADR 0011](0011-building-catalog-and-rigid-impact-scenarios.md) 的碰撞损伤路径；保留其有限质量刚体、接触门槛和不重复施加物理冲量的约定。
- 后续 [ADR 0017](0017-progressive-impact-unloading.md) 替代本记录的一次性全场待断名单与拆分后原始冲量重分组。下述全部单块的首轮验收是已观察到的历史行为，已不作为合理破碎程度的通过标准。

## 背景与复现

原撞击判据只把直接命中 Chunk 的接触冲量分配给其相邻 Bond，无法表达巨大刚体簇内部用于阻止上层质量继续运动的力与弯矩。落地可以使底层掉几片，但上方绝大部分仍保持一个刚体。

使用十层 `highrise_slab` 原资产构造确定性复现：清理下半部以提供实际地面上的落地区域，保留上半部 236 个 Chunk 及其内部连接；不给初速度或预制坍塌轨迹，仅由重力下落。

- 旧实现首次地面接触速度约 `18.31 m/s`，最大接触冲量约 `16.91 MN·s`。
- 旧实现断开 21 条接触附近连接，形成 4 个单块及一个 232 块的大簇，约 98.3% 的上半部仍连成整体。
- 新回归要求不仅出现落地碰撞，还要断开资产坐标 `Y>20 m` 的内部楼层连接，避免把底部小碎片当成上层结构破坏。

## 已采用的决策

### 接触采样与事件资格

仍在 Avian 物理求解完成后采样法向冲量，单位 N·s；只有法向接近速度至少 `2 m/s` 且确实收到非零求解冲量的结构接触才进入撞击判定。

接触历史仅标记已经消费有效冲量的接触事件。提前出现、尚未获得正冲量的接触不会消耗后续撞击机会；持续接触也不会每帧重复使用一次撞击。只有接触结束后才允许同一碰撞体对开始新的撞击事件。

单块和静态簇继续使用 ADR 0011 的局部判据。含多个 Chunk 的动态簇按刚体聚合本次新接触的逐点冲量及其在各 Chunk 质心处的冲量矩，转换到原资产坐标系并保存为待处理事件。

### 从刚体冲量中分离可引起内部应力的载荷

以下计算均在资产坐标系中使用 f64。节点质量为 `m_i`、质心为 `c_i`、自身质心惯性为 `I_i`；簇总质心为 `C`，`r_i=c_i-C`。先聚合质量与完整平行轴惯性：

```text
M = sum(m_i)
I = sum(I_i + m_i * ((r_i dot r_i) 1 - r_i r_i^T))
J = sum(J_contact_i)
L = sum(L_contact_i + r_i × J_contact_i)
delta_v = J/M
delta_omega = inverse(I)*L
```

其中 `L_contact_i` 是接触点相对该 Chunk 质心的冲量矩，不是重复的整体轨道角动量。对应的惯性平衡节点力与力矩为：

```text
F_i = (J_contact_i - m_i * (delta_v + delta_omega × r_i)) / tau
T_i = (L_contact_i - I_i * delta_omega) / tau
tau = 0.01 s
```

与原撞击路径一致，`tau` 是明确的游戏原型标定时间，不是渲染帧间隔；此模型没有测量材料真实接触持续时间。减去整体刚体加速部分后，载荷应满足：

```text
sum(F_i) = 0
sum(r_i × F_i + T_i) = 0
```

这使未直接碰地的上层质量也参与冲击内力，并保证纯粹一致的刚体速度变化不产生虚假内部载荷。自由落体没有外部接触事件，不向该路径输入静态 `m*g`。

### 数值规范约束与真实 Anchor 的区别

调用 `stress::solve_with_gauge` 求解完整动态分量的弹性连接网络，重力输入为零，忽略清单中的物理 Anchor，并仅固定一个节点的六个数值自由度以移除刚体平移/转动零模态。

这个数值规范点不写入资产或 BuildingInstance 的 Anchor，不生成固定物理刚体，也不固定残骸的世界位姿。调用者检查节点载荷的总力和总力矩相对误差不超过 `1e-6`，求解器同样拒绝不平衡载荷；解出的规范点反力/反力矩相对接触载荷尺度应不超过 `1e-5`。独立测试切换规范点后比较每条 Bond 的力和力矩，避免把某个节点当成虚构的实际支撑。

应力恢复沿用 ADR 0010 的完整面积二阶矩、真实截面顶点、拉压剪限值及弯曲/扭转近似；缺少截面几何的无图形夹具仍显式使用原来的等二阶矩椭圆近似。失败或规范反力过大时，不使用无效的全簇应力驱动断裂，保留失败计数，并退回已有的直接接触局部冲量判据。

这些虚拟分析载荷只用于判断连接是否失效。Avian 已经施加的冲量不会第二次施加到旧簇或新簇；拆分仍按 ADR 0009 继承当前刚体速度场。

### 有界求解与拓扑变化

- 同一物理步对同一动态簇的新接触先聚合，再进入队列；每固定步最多执行一次重型动态簇结构求解。其他有效事件保留到后续步，不因超过本步求解预算直接丢弃。
- 事件保留原成员和各接触 Chunk 的资产坐标冲量/冲量矩。若处理前成员已经拆分或被点击移除，则按当前仍存活的簇重新分组，只将直接接触载荷交给仍包含其 Chunk 的分量，并对新分量重新作惯性平衡。
- 每次重新分组都会得到更小的成员列表；消失的建筑、没有存活接触节点的事件和没有内部连接的单块会退出队列，因此拆分重分组本身不会无限循环。
- 连接失效仍合并到原稳定 ID 队列，每固定步全局最多断开 8 条连接。合格连接保留到后续步提交，不直接删除整簇几何。
- `ImpactStats` 记录结构求解次数、失败次数、待处理事件数、最长实际求解耗时、载荷平衡误差和规范点反力误差。每步一个求解并不是固定毫秒预算，过多同时撞击仍可能造成排队延迟。

## 已实现与无图形验证

- `src/projectiles.rs`：有效冲量事件资格、动态簇逐点冲量及冲量矩快照、f64 惯性平衡、规范点求解、排队与拓扑重分组，以及诊断。
- `src/stress.rs`：独立数值规范入口，原有锚定自重求解接口不变；真实 Anchor 不被改写。
- `src/projectile_tests.rs` 的 5 项相关测试已全部通过，其中新增以下回归：
  - 同一 236 块上半楼体仅靠重力落地，在 300 个固定步内断开内部楼层连接并进一步拆分；诊断运行中累计断开 716 条连接，最大存活簇由旧实现的 232 块降到 1 块。
  - 全过程检查位姿、线速度、角速度有限；拆分总质量保持；接地前的自由落体不触发冲击结构求解或断裂。
  - 载荷总力和总力矩误差通过 `1e-6` 相对界限，规范反力通过 `1e-5`，结构求解失败计数为零。
  - 非零接触力与接触力矩的惯性平衡、不同数值规范点下 Bond 力/力矩一致。
  - 一致的刚体线速度和角速度变化产生零内部冲击载荷。
- 原球体/立方体真实碰撞保留 8 吨质量与原碰撞形状、低速 1 m/s 不断裂及持续接触不重复损伤的回归继续通过。

诊断期间这 5 项测试合计约 9.97 秒。新模型会实际产生更多刚体和接触，不能把旧实现几乎不破碎的运行时间当成同工作量性能基线，也不由该测试时间声称图形帧率。

## 备选方案与取舍

- 降低全部材料强度或无条件炸散整簇可以产生视觉破碎，但不能解释上层惯性质量和远离碰撞点的弱连接失效，本轮不采用。
- 只扩大直接接触范围仍忽略力矩和整个簇的惯性分布；保留此路径作为无效全簇分析的独立局部回退。
- 完整瞬态弹性波、接触持续时间积分或可变形 FEM 能描述更多现象，同时需要不同求解器和标定，本轮采用有明确时间参数的准静态冲量内力近似。
- 永远固定一个动态 Chunk 会引入实际外部支撑；当前只用平衡载荷下可检验的数值规范，并验证规范点选择不改变连接内力。

## 限制与未决问题

- 当前不是完整动态应力、波传播、裂纹能量或大变形模型；未计入冲击间原有旋转的离心内力、可见挠曲或材料应变率。
- 延迟事件按当前存活分量重新平衡，不能声称精确重放接触瞬间的历史拓扑；在高度拥塞和连续拆分时，结果与即时分析可能不同。
- 当前接触资格先检查接触对的合冲量长度。现有凸碎块与凸地面盒体的落地法向同向，不产生相互抵消；未来一个碰撞体含多个对向代理或非凸接触时，零合冲量但非零冲量矩的纯力偶可能被门槛跳过，需要按逐点冲量大小另行扩展。
- 进一步的队列合并、并行求解、上限策略及碎块/接触预算应单独测量；不能为了性能静默丢弃已经确认的撞击损伤。
