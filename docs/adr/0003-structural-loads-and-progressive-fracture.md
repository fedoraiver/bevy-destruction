# ADR 0003：结构承载、连接损伤与渐进断裂

## 状态

- 部分已采用（六自由度界面网络、自重求解及过载断裂已实现，具体边界见 ADR 0010）
- 日期：2026-11-16
- 更新：2026-11-17。本文保留早期设计方向；[ADR 0010](0010-elastic-interface-stress-and-overload-fracture.md) 明确本轮已采用的构成关系、求解器、失效规则及完成的验证。动态内力、弱连接等未被该记录采用的内容仍为提议。

## 背景

仅根据伤害删除连接并寻找失去锚点的连通分量，可以实现碎块脱落，但无法判断细柱过载、悬臂根部弯曲断裂或多支点之间的载荷重分配。项目需要独立于几何预破碎和刚体接触的承载模型。

GDC 演讲包含连接破坏、不同负载分量和求解器方面的讨论。演讲中出现的稀疏直接法及 Cholesky 对比涉及 Embark 的刚体求解器；不能据此断言其采用本文所提议的独立静态弹性网络或完整 FEM。以下模型属于本项目的实现候选。

## 决策提议

### 首个承载模型

采用具有六自由度节点的小变形线性弹性连接图：每个结构节点包含三维平移和三维转动；Bond 表达轴向、剪切、弯曲与扭转刚度。它是用于近似连接内力的离散结构模型，不声称是建筑材料的完整连续体模拟。

初期只对具有有效永久锚定边界的结构分量进行准静态承载分析。在施加边界条件后求解 `K u = f`，由相对位移和转动回算 Bond 的界面力与力矩。载荷向量同时包含力和力矩，锚点必须明确锁定哪些自由度。第一版可以从完全固定锚点开始，其他边界形式需单独验证。

求解出的微小位移首先只用于计算内力；物理和画面仍采用 ADR 0001 的刚性 Cluster。这能验证承载与断裂，但不能表现真实挠曲，也不适合未经验证地扩展到大变形、屈曲或弹性振动。

Bond 需要局部坐标、连接位置、面积、材料刚度，以及用于弯曲和扭转的截面参数。仅有法线和面积不足以区分细长截面在不同方向的弯曲能力。任意预破碎界面的截面近似、等效连接长度和刚度标定需要通过原型确定。

### 载荷重分配与断裂

对受影响的整个连通结构分量求解平衡，包括闭环和多个锚点，而不是沿任意树或最短路径累计重量。局部断裂可能改变远处连接内力，因此“仅更新受损点附近”必须经过误差验证，不能作为初始正确性假设。

断裂循环为：组装有效结构与载荷、求解、回算连接负载、更新损伤、移除失效连接，再对受影响分量重新求解。每个固定步需要限制循环轮次和工作量，未完成工作显式保留。拓扑和刚体重建在物理步边界批量提交。

内力判断需要区分拉伸、压缩、剪切，并将弯矩和扭矩通过截面模型转换为相应应力或等效利用率。不同材料可以具有不同方向与受力类型的承载限值。具体组合准则和材料参数是待标定内容，不能把所有负载简单相加为无量纲“力值”。

### 求解器选择与失败处理

小图先使用便于检查的稠密直接参考解，并以解析场景、残差和内力平衡验证组装。实际规模下采用哪种稀疏方法尚未锁定：稀疏 Cholesky、预条件共轭梯度及其缓存策略，需要结合图规模、条件数、拓扑变化频率和实测成本选择。

充分约束、有效的线性弹性模型可以形成适合对称正定方法的系统，但该性质必须验证。缺少约束、机构运动、错误连接参数或严重退化可能导致奇异或病态问题。不能为了让求解器返回结果而任意添加刚度、把所有节点固定或把失败结果当成零应力。

需要记录收敛状态、迭代次数、残差和异常分量，并对平移、转动及不同单位的尺度作合理归一化。参考解与实际求解器应在同一输入上比较。

失败的分量应标为承载结果无效，保留诊断信息，采用受限重试或经过验证的回退。初期可暂停该分量由承载结果驱动的新增断裂；直接游戏伤害和已经确定的拓扑变化仍按其规则处理。此前有效结果可以用于调试显示，但不能冒充本次已经收敛的承载结果。失败不得自动触发整楼坍塌，也不得永久静默跳过求解。

### 初始负载与时间积分

可以选择记录资产实例在完好状态、指定锚定与重力配置下的初始连接负载，辅助参数标定或构造玩法阈值。该 baseline 是可选项，不是让建筑稳定的必需条件；初始自重仍应实际参与承载分析。

若采用 baseline，需要随配置标识记录其定义。受损后重新求解不能把当前负载反复登记为新的完好 baseline，否则连接会逐次适应越来越高的负载，掩盖渐进失效。也不能只比较增量而无条件忽略原有自重。baseline 如何参与强度阈值，以及配置变化后的显式重建规则，需要另行验证。

持续过载通过固定时间步积分损伤，明确使用 `dt`，避免渲染帧率决定断裂速度。同一固定步内的多轮断裂重算不能每轮重复累计完整 `dt`；若采用子步积分，各子步时长之和应等于实际经过的时间。可以从超过利用率阈值后累计损伤的简单模型开始，并为极端过载保留立即断裂规则。衰减、疲劳、强度退化和刚度退化应分别定义；是否需要这些扩展尚未决定，不能把它们隐含为每帧固定扣血。

### 动态簇与渐进松动的范围

脱离永久锚点的 Cluster，初期交给物理后端模拟运动，通过撞击损伤继续破坏。不能对自由落体簇直接施加静态自重承载求解，否则均匀重力可能产生本不应存在的内部载荷和自发断裂。

动态簇的结构内力若要进一步求解，需要考虑整体线加速度、角加速度、旋转效应及外部接触载荷的一致性。自由落体、持续接触支撑和旋转簇是不同边界情形。该能力属于后续验证范围，初期不以静态 `mg` 近似替代。

碰撞冲量与静态力使用不同单位和时间含义。初期撞击损伤可以使用明确标定的冲量指标；若转换为力或应力，需要明确作用时间和积分约定，不能任意除以渲染帧间隔。用于评估破坏的同一外部冲量也不能重复施加到物理刚体。

初期的渐进断裂是损伤随时间累积和载荷逐步重分配，不包括刚性 Cluster 内的可见松动。未来若支持 ADR 0001 的弱连接，需要先分成不同 Cluster，再通过允许相对运动的物理约束连接，并处理该约束的载荷反馈和最终断开。同一 compound 内降低 Bond 强度不能替代这项能力。

## 备选方案与取舍

- **仅连通性和经验承载规则**：开发快，适合验证拆簇管线，但难以一致处理闭环、悬臂和多支点。可以作为独立基线比较，不应冒充本提议的承载模型。
- **虚拟刚体或约束冲量求解**：更接近动态、撞击和弱连接问题，也可以作为结构求解候选；其步长、阻尼、收敛和接触耦合需要额外验证。准静态弹性图优先用于隔离并验证自重承载，不意味着它在瞬态问题上更准确。
- **完整非线性 FEM 或连续体模型**：可覆盖更多材料和变形行为，但资产、求解和参数标定成本明显提高，超出首轮目标。
- **直接集成现有破坏 SDK**：可以减少部分算法工作，但需验证构建、平台、许可证、Bevy/物理后端边界和可定制性；参考 Blast 文档不等于已经决定依赖 Blast。

独立结构求解器与刚体接触求解器是两个层次。当前提议不要求重写物理后端；只有原型证明约束稳定性、反馈能力或性能成为关键限制时，才评估定制刚体求解器。

## 验证与未决问题

- 悬臂的根部力矩随载荷距离增加，断裂位置和方向符合模型预期。
- 对称双支点分担载荷；不同刚度路径在闭环中产生合理分配；结果不依赖图遍历顺序。
- 移除支柱后，其余支撑的负载发生变化，并能产生受预算控制的连锁断裂。
- 初始自重下应力和反力平衡；baseline 开关及断裂重算不会悄悄重置承载基准。
- 在不同固定步长和渲染帧率下，持续过载的断裂时间在定义的误差范围内一致。
- 欠约束、退化截面和求解不收敛能产生可诊断结果，不被解释为无限强或零负载。
- 自由落体簇不会因静态自重算法自碎；撞地和二次撞击能沿单独损伤路径产生破坏。
- 比较参考解与候选稀疏方法的误差、残差、峰值耗时和拓扑变更成本，再决定默认求解器。
- 弱连接引入前，应另行验证关节形式、载荷反馈、接触支撑及动态内力的一致性。
