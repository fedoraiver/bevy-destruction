# 测试指南

按改动影响选择测试层级。仓库根目录的 Rust 检查和离屏验收命令见 [README](../README.md#验证)。

## 选择验证入口

| 改动范围 | 验证方法 |
| --- | --- |
| 清单校验、图连通性、应力计算等纯逻辑 | 用所属模块的测试验证边界和解析结果。保留数值夹具的输入几何与容差。[资产](../src/asset/tests.rs) · [结构图](../src/structure/tests.rs) · [弹性求解](../src/stress/tests.rs) |
| 组件关系、调度、接触或分簇行为 | 在最小 Bevy `App` 中安装所需插件和生产系统，按真实顺序推进时钟。断言系统消费时的组件、速度、质量或连接状态。[刚体簇](../src/physics/tests.rs) · [承载运行时](../src/stress_runtime/tests.rs) · [真实接触](../src/projectiles/tests.rs) |
| 玩家输入、相机、材质、特效或完整应用装配 | 运行匹配的离屏验收用例，读取验收报告、日志和必要的阶段截图。[无窗命令](../README.md#无窗验收) |
| Blender 导出、凸代理、GLB 或接触面格式 | 运行 Blender 测试，并用 Rust 资产测试验证运行时消费入口。[Blender 验证](../tools/blender/README.md) · [Rust 资产测试](../src/asset/tests.rs) |
| 文档 | 核对源码依据、参数和命令，检查相对链接、锚点与格式。 |

涉及逐帧与固定步交接时，按改动覆盖一帧内零次、一次或多次固定步。在状态应当可见的时点断言，避免补跑系统掩盖顺序问题。物理用例用模拟时间推进，性能测量使用墙钟时间。

## 选择离屏用例

| 用例 | 主要覆盖 |
| --- | --- |
| `controls`、`gameplay` | 原生键鼠消息、飞行瞄准、点击破坏和发射撞击物。BRP 可用于布置初始相机，行为由实际输入触发。 |
| `smoke` | 场景实例化、点击破坏、边带与粒子预算、烟尘回收及可选回放。 |
| `physics`、`stress` | 失支撑、运动拆簇、质量与速度继承、休眠、自重和渐进断裂、刚球与方块。 |
| `landing`、`collapse` | 大块落地后的内部断裂、成组残骸和质量平衡，以及偏侧残余支撑引起的自然倾倒。 |
| `material`、`contact`、`force` | 材质随刚体运动、断面遮罩和深度遮挡，以及受力热力、详查和实际冲量。 |
| `profile` | 离屏墙钟帧耗时和热路径采样。通过单独运行获取。 |

离屏用例应以程序状态、数值或图像判据给出结果。每次运行按用例保存证据，报告验证的场景、预期、实际结果和覆盖范围。验证结果可从 `summary.json` 跟踪到各用例报告。固定帧截图和原生输入均由项目验收脚本采集。[验收脚本](../scripts/acceptance/run.py) · [交互步骤](../scripts/acceptance/gameplay.py)
